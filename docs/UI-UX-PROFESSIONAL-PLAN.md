# پلانی پرۆفیشناڵ و فەنکشناڵی UI/UX — Wazn Express
## Plan: Very Professional UI/UX + Effective Functions

ئەم پلانە دوو بەشی سەرەکی دەگرێتەوە: **١) پرۆفیشناڵی بینراوی (Visual)** و **٢) فەنکشنی کارا (Effective Functions)**.

---

## ئەوەی ئێستا جێبەجێکراوە ✅

- کۆمپۆنێنتە یەکگرتووەکان: `DashboardHero`, `FinancialCard`, `StatsCard`, `DashboardSection`, `ChartEmpty`

## بەشی یەکەم — پرۆفیشناڵی بینراوی (Visual Professional)

### ١. کارت و ڕیزبەندی
- **کارتی داشبۆرد:** یەک کۆمپۆنێنتی `DashboardCard` بۆ هەموو کارتەکان (header یەکگرتوو، border، shadow، radius) تا UI یەک شێواز بێت.
- **ترتیبەکانی کارت:** لە مۆبایڵدا کارتە مالییەکان بە یەک ڕیز (١ ستون)، لە تابلێت ٢ ستون، لە دێسکتۆپ ٤ ستون؛ هەمان شێواز بۆ کارتە ئامارییەکان.
- **سەرەوەی بەش:** هەر بەشێک ناونیشانی ڕوون (وەک «ئاگاداریەکان»، «چالاکییە تازەکان») و ئەگەر پێویست «بینینی هەموو» لە لای ڕاست.

### ٢. چارت و داتاڤیز
- **چارتەکان:** هەمان بەرزی جێگیر، tooltip بە فۆرماتی ژمارە و وەرگێڕدراو (i18n)، لە مۆبایڵدا scroll یان resize بە شێوەیەکی ڕێک.
- **رەنگی چارت:** بەکارهێنانی `--chart-1` تا `--chart-5` لە CSS variables بۆ یەکگرتوویی لەگەڵ تێما.
- **Skeleton بۆ چارت:** کاتێک داتا بارنەکراوە، شوێنی چارت skeleton نمایش بدات (کەم layout shift).

### ٣. سایدبار و ڕێنیشان
- **Active state:** هێڵ یان پسپۆڕی رەنگ لە لای ئایتمی چالاک (ئێستا خاڵی سەوز هەیە؛ دەتوانرێت هێڵێکی تەنک زیاد بکرێت).
- **Spacing و hover:** فەرامۆش نەکراو بێت؛ گرووپەکان و ئایتمەکان spacing یەکگرتوو.
- **داخستنی سایدبار لە مۆبایڵ:** دوای هەڵبژاردنی لاپەڕە سایدبار خۆکار دادەخەیت.

### ٤. تایپۆگرافی و رەنگ
- **فۆنت:** یەک scale (وەک `text-sm` بۆ بەڵگە، `text-lg` بۆ سەرەوەی کارت، `text-2xl/3xl` بۆ titiles).
- **رەنگ:** لە هەموو شوێنێکدا CSS variables (`primary`, `muted`, `destructive`, `success`) بەجیاتی کۆدی hex جیاواز.

### ٥. مایکرۆ-ئینتەرەکشن و بارکردن
- **Transition:** هەمان `transition-all duration-200/300` بۆ کارت و دووگمە.
- **Loading:** بۆ هەر بەشی داتادار skeleton یان spinner یەکگرتوو؛ دەقێکی کورت وەک «بارکردن…» لە شوێنی ناوەڕۆک.
- **Empty state:** هەمیشە ئایکۆن + دەق + (ئەگەر گونجاو بێت) CTA وەک «تۆمارکردنی یەکەم پاکەت».

## بەشی دووەم — فەنکشنی کارا (Effective Functions)

### ١. فلتەر و مەودایە کات (Date Range)
- **داشبۆرد:** فلتەری «٧ ڕۆژ / ٣٠ ڕۆژ / ١٢ مانگ» یان date picker بۆ چارتەکان و ئامارەکان، بۆ ئەوەی بەکارهێنەر بە خێرایی مەودایە کات بگۆڕێت.
- **ڕاپۆرتەکان:** هەمان فلتەری مەودایە کات لە پەڕەکانی ڕاپۆرت و دارایی.

### ٢. هەڵبژاردنە خێراکان (Quick Actions)
- **داشبۆرد:** دووگمەکانی خێرا بە ناونیشان ڕوون و ئایکۆنی گونجاو (وەک تۆمارکردنی پاکەت، دروستکردنی باچ، تۆمارکردنی پارەدان، سکان، کڕیار، ڕاپۆرت)؛ لە مۆبایڵدا گونجاو بۆ تاچ (min 44px).
- **Shortcuts (ئەگەر گونجاو بێت):** کۆمەڵە shortcut یەکگرتوو (وەک Ctrl+K بۆ search) لە ئاستی ئەپ.

### ٣. ئاگاداری و نۆتیفیکەیشن
- **ئاگاداریەکانی داشبۆرد:** لیستی ئاگاداریەکان بە لینک بۆ پەڕەی وردەتر (پاکەتی مەترسیدار، باچی درەنگ، قەرزداران).
- **نۆتیفیکەیشن (ئەگەر backend بەردەست بێت):** ئایکۆنی زەنگ لە header و dropdownی نۆتیفیکەیشنە تازەکان.

### ٤. گەڕان و دەستڕاگەیشتن بە خێرایی
- **گەڕان:** گەڕان لە سەر کڕیار، پاکەت، یان کۆدی تراکینگ لە header یان لە داشبۆرد (وەک search bar یەکەم شت لە سەرەوە).
- **لینکە خێراکان:** لە کارتی «قەرزداران» و «باچە چالاکەکان» و «باشترین کڕیاران» لینکی «هەموو» بۆ پەڕەی تەواو.

### ٥. Export و ڕاپۆرت
- **داشبۆرد:** دووگمەکانی «ڕاپۆرتی ڕۆژانە» و «ڕاپۆرت بە ماوە» (ئێستا هەن)؛ دڵنیابوون لەوەی PDF و (ئەگەر پێویست) Excel بە فۆرماتی ڕێک و وەرگێڕدراو.
- **ڕاپۆرتەکان:** فلتەری مەودایە کات + دوگمەی download یەکگرتوو.

### ٦. دەستڕاگەیشتن و RTL
- **Keyboard:** focus visible بۆ هەموو دووگمە و لینک؛ ترتیبی tab ڕێک.
- **RTL:** لە هەموو بەشە visualەکاندا RTL دروست (margin، padding، سایدبار، چارت ئەگەر پێویست بێت).
- **Contrast:** چێککردنی contrast لە light/dark بۆ خوێندنەوەی ئاسان.

## ترتیبەکانی جێبەجێکردن (پێشنیار)

| قۆناغ | کارەکان | مەودایە کات (تەخمینی) |
|--------|---------|-------------------------|
| **A** | DashboardCard یەکگرتوو + section titles + چارت skeleton + polish کارت/چارت | ٢–٣ ڕۆژ |
| **B** | فلتەری مەودایە کات لە داشبۆرد (٧/٣٠ ڕۆژ/١٢ مانگ) + پەیوەندیکردن بە چارت و ئامار | ١–٢ ڕۆژ |
| **C** | باشکردنی سایدبار (active state، spacing، مۆبایل) + تایپۆگرافی یەکگرتوو | ١ ڕۆژ |
| **D** | گەڕان لە header یان داشبۆرد (کڕیار/پاکەت/کۆد) | ١–٢ ڕۆژ |
| **E** | Empty state یەکگرتوو لە هەموو بەشەکان + CTA + loading states | ١ ڕۆژ |
| **F** | RTL و contrast و keyboard focus (accessibility) | ١ ڕۆژ |

دەتوانیت دەستپێبکەیت لە **قۆناغ A** (کارت و چارت و سەرەوە پرۆفیشناڵتر)، دواتر **B** (فلتەری کات)، و پاشان C–F بە پێی prioritization.

## کۆتایی

- **پرۆفیشناڵی بینراوی:** کارت یەکگرتوو، چارت ڕێک، سایدبار ڕوون، تایپۆگرافی و رەنگ یەکگرتوو، loading و empty state ڕوون.
- **فەنکشنی کارا:** فلتەری مەودایە کات، quick actions ڕوون، ئاگاداری و لینک، گەڕان، export، دەستڕاگەیشتن.

ئەگەر بتەوێت دەستپێبکەین لە قۆناغێک (وەک A یان B)، تەنها بڵێ لە کۆمەڵە کارەکە دەستپێدەکەین.
