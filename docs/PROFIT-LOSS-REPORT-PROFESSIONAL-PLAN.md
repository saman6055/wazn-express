# پلانی پرۆفیشنالکردنی ڕاپۆرتی قازانج و زیان
## Profit & Loss Report — Very Professional Renewal Plan

ئەم پلانە تەنها بۆ **ڕاپۆرتی قازانج** (`/reports/profit`) نووسراوە، بۆ ئەوەی UI/UX و لۆژیکی ڕاپۆرت زۆر پرۆفیشنال و ڕوون بن.

---

## ١. ئەوەی ئێستا هەیە (وەسفێکی کورت)

**پەڕە:** `client/src/pages/ProfitReports.tsx` — ڕێگا: `/reports/profit`

- **Header:** بانێری گرادیێنت (violet)، ناونیشان «ڕاپۆرتی قازانج»، نەخشەی «شیکردنەوەی قازانج و داهات بەپێی جۆر و مانگ»، دوگمەی **Excel** و **هەڵبژاردنی ساڵ** (٢٠٢٦).
- **کارتە ئامارییەکان (٤):** تێکڕای مانگانە، کۆی گواستنەوە، کۆی داهات، کۆی قازانج.
- **تابەکان:** ڕاپۆرتی مانگانە | بەپێی جۆر | وردەکاری.
- **تابی مانگانە:** خشتە بە مانگ، فول پاکیج (قازانج+ژمارە)، کۆمیشن، پاکەت، کۆی قازانج، بەراورد (ئایکۆن + ڕێژە). دوو کارت: باشترین مانگ / خراپترین مانگ.
- **تابی بەپێی جۆر:** کارتەکانی فول پاکیج، کۆمیشن، پاکەت (ژمارە، کۆی قازانج/داهات، تێکڕا).
- **تابی وردەکاری:** فلتەری جۆری ئۆردەر، ئاماری کورت، خشتەی ئۆردەرەکان (کۆد، کاڵا، جۆر، نرخی کڕین/فرۆشتن، گواستنەوە، قازانج، مارجین) — نیشاندانی ٥٠ یەکەم.
- **داتا:** `fullPackage.getMonthlyProfitReport`، `fullPackage.getProfitByOrderType`، `fullPackage.getProfitReport`.
- **Export:** Excel بە سەرۆکی کوردی/ئینگلیزی و ژمارەکان.

**کەمەکان:** بەراوردی مانگ (+0.0% / -100%) ڕوون نییە یان هەڵەیە؛ بەها نێگەتیڤ (وەک فول پاکیج -$228) ڕووناکی پێنەدراوە؛ چارت/گرافیک نییە؛ هەندێک دەق تەنها کوردی یان تەنها ئینگلیزیە؛ PDF export نییە؛ پوختەی بەڕێوەبەر نییە؛ فۆرماتی پارە لە هەموو شوێنێکدا یەکگرتوو نییە (وەک `formatCurrency` لە یەک شوێن).

## ٣. پلانە وردەکان

### ٣.١ لۆژیکی بەراورد و ڕێژە

- **بەراوردی مانگ:** ئێستا `month.comparison.profitChangePercent` پیشان دەدرێت. دڵنیابوون لەوەی لە سێرڤەر یان client بە ڕاستی ژمارە دەکرێت: **(قازانژی ئەم مانگە − قازانژی مانگی پێشوو) / قازانژی مانگی پێشوو × 100**؛ ئەگەر مانگی پێشوو ٠ بێت، نیشاندانی «–» یان «سفر پێشوو» بەجیاتی -100% یان +0.0% گومانلێکەر.
- **نێگەتیڤ:** بەها نێگەتیڤەکان (قازانژی سڕاوە، تێچوو) بە رەنگی سوور یان `-$X.XX` ڕوون پیشان بدرێن؛ لە خشتە و کارتدا یەک شێواز.
- **سفر:** مانگە بێ داتا «$0.00» یان «–» بە شێوازێکی یەکگرتوو.

### ٣.٢ فۆرماتی ژمارە و پارە

- **یەک utility:** دروستکردنی `client/src/lib/format.ts` (ئەگەر نییە) بە `formatCurrency(value: number)`, `formatNumber(value: number)`؛ بەکارهێنانی لە هەموو `ProfitReports.tsx` و پەڕەکانی تر.
- **پارە:** هەمیشە `$1,234.56` یان `-$123.45`؛ هەزار separator بۆ ژمارە گەورە.
- **ڕێژە:** `+5.2%` یان `-10.0%` یان `–` کاتێک بەراورد ناممکینە.

### ٣.٣ چارت و داتاڤیز

- **سەرەوەی ڕاپۆرت یان لەژێر KPI:**
  - **چارتی مانگانە:** بار یان لاین بۆ قازانج/داهات بەپێی ١٢ مانگ (Recharts: BarChart یان LineChart)؛ رەنگ بە CSS variables.
  - **چارتی بەپێی جۆر:** پای یان دۆنات بۆ قازانجی فول پاکیج / کۆمیشن / پاکەت.
- **Empty state:** کاتێک داتا نییە، ئایکۆن + «بۆ ئەم ساڵە داتا نییە» یان «هیچ داتایەک نییە».
- **تابی مانگانە:** چارت لە سەرەوەی خشتە یان لە تەنیشت؛ خشتە وەک ئێستا بە polish.

### ٣.٤ پوختەی بەڕێوەبەر (Executive Summary)

- **شوێن:** لە سەرەوەی ناوەڕۆک، یان لەژێر کارتە ئامارییەکان.
- **ناونیشان:** «پوختە» / «Executive Summary» (i18n).
- **ناوەڕۆک:** ٢–٤ ڕیز: «لە ساڵی X گشتی قازانج $Y، گشتی داهات $Z؛ باشترین مانگ: مانگەکە ($A)، خراپترین: مانگەکە ($B).»
- **چاپ/PDF:** ئەم پوختەیە لەگەڵ KPI و خشتە یان چارت بچێتە ناو PDF.

### ٣.٥ Export (Excel و PDF)

- **Excel:** وەک ئێستا بەردەستە؛ دڵنیابوون لە فۆرماتی پارە و ژمارە (هەزار separator)؛ ناونیشانی فایل وەک `profit-report-2026.xlsx`.
- **PDF:** زیادکردنی دوگمەی «چاپ / PDF»؛ دروستکردنی لاپەڕەیەک یان دوو بە ناونیشان، بەروار، KPI، خشتەی مانگانە (و ئەگەر گونجاو بێت پوختە و چارتی بچووک).

### ٣.٦ i18n و RTL

- **هەموو دەقەکان** بە `t('profitReport.xxx')` یان keyی گونجاو؛ زیادکردنی keyەکان لە `en.json`, `ku.json`, `ar.json`, `zh.json` بۆ: ناونیشان، وەسف، سەرۆکی خشتە، ناونیشانی کارت، تابەکان، پوختە، empty state، دوگمەکان.
- **RTL:** لە کوردی/عەرەبیدا spacing و alignment و سەرۆکی خشتە ڕاستەوخۆ چەک بکرێن.

### ٣.٧ یەکگرتی UI

- **کارتی ئامار:** کۆمپۆنێنتێکی یەکگرتوو وەک `ReportMetricCard` (ناونیشان، بەها، ئایکۆن، رەنگ) بۆ ٤ کارتی سەرەوە.
- **خشتە:** سەرۆکی ڕوون، رەنگی قازانج/زیان یەکگرتوو، hover و spacing.
- **تابەکان:** ئایکۆن بۆ هەر تاب؛ loading skeleton یەکگرتوو.

### ٣.٨ وردەکاری و drill-down

- **تابی وردەکاری:** پاگینەیشن یان «بینینی هەموو»؛ لینک لەسەر کۆدی ئۆردەر بۆ پەڕەی وردەکاری ئۆردەر (فول پاکیج/کۆمیشن).
- **فلتەر:** ئەگەر گونجاو بێت، فلتەری مەودایە کات (ساڵ + مانگ) بۆ وردەکاری.

## ٦. تێبینی کورت

- **سەرەتا** قۆناغە A و B پێش چارت و PDF باشترن تا لۆژیک و دەق ڕاست بن.
