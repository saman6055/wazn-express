# پلانی سیستەمی فول پاکیج - Wazn Express
## وەشانی 2.0 - بەڵگەنامەی تەواو و پڕۆفیشناڵ

---

## 1. پێشەکی

سیستەمی فول پاکیج یەکێکە لە گرنگترین بەشەکانی Wazn Express کە ڕێگە دەدات بە کۆمپانیا کاڵا بکڕێت و بیفرۆشێتەوە بە کڕیارەکان. ئەم بەڵگەنامەیە پلانێکی تەواو پێشکەش دەکات بۆ نوێکردنەوەی ئەم سیستەمە بە سێ جۆری جیاوازی سفارش.

---

## 2. سێ جۆری سفارش

سیستەمی نوێ سێ جۆری سەرەکی سفارش پشتگیری دەکات کە هەریەکە تایبەتمەندی و لۆجیکی قازانجی خۆی هەیە.

### خشتەی بەراوردکردن

| تایبەتمەندی | فول پاکیج | داواکاری کڕین | کڕین بە عمولە |
|-------------|-----------|---------------|---------------|
| **کۆدی جۆر** | `full_package` | `purchase_request` | `commission` |
| **کێ دەستپێدەکات** | کۆمپانیا | کڕیار (پۆرتال) | کڕیار یان کۆمپانیا |
| **کێ کاڵا دەدۆزێتەوە** | کۆمپانیا | کڕیار لینک دەنێرێت | کڕیار لینک دەنێرێت |
| **کێ نرخ دیاری دەکات** | کۆمپانیا | کۆمپانیا | کڕیار نرخ دەزانێت |
| **خاوەنی کاڵا** | کۆمپانیا | کۆمپانیا (تا فرۆشتن) | کڕیار |
| **نرخی گواستنەوە لەسەر کێ** | کۆمپانیا (کۆست) | کۆمپانیا (کۆست) | کڕیار (فرۆشتن) |
| **سەرچاوەی قازانج** | فرۆشتن - کڕین - کۆست | فرۆشتن - کڕین - کۆست | عمولە + قازانجی باچ |

---

## 3. جۆری یەکەم: فول پاکیج (Full Package)

### 3.1 پێناسە

فول پاکیج ئەو کاتەیە کە کۆمپانیا کاڵایەک دەدۆزێتەوە، دەیکڕێت، و بە نرخی بەرزتر دەیفرۆشێتەوە بە کڕیار. کۆمپانیا خاوەنی کاڵاکەیە تا کاتی فرۆشتن.

### 3.2 پرۆسەی کارکردن

**قۆناغی یەکەم: دۆزینەوە و نرخدانان**

کۆمپانیا کاڵایەک دەدۆزێتەوە لە بازاڕی چین (1688، Taobao، و هتد) و نرخی کڕین و فرۆشتن دیاری دەکات. نرخی فرۆشتن پێکدێت لە نرخی کڕین بەزیادی قازانجی خواستراو.

**قۆناغی دووەم: فرۆشتن بە کڕیار**

کاتێک کڕیار ڕازی بوو، پارەی نرخی فرۆشتن لەسەر حسابی کڕیار دەچێت و ئینڤۆیس دروست دەبێت. لەم قۆناغەدا کاڵاکە هێشتا نەگەیشتووە.

**قۆناغی سێیەم: کڕین و گواستنەوە**

کۆمپانیا کاڵاکە دەکڕێت، دەیخاتە باچ، و دەینێرێت. لەم قۆناغەدا پاکەتێک دروست دەبێت بە جۆری `company_owned`.

**قۆناغی چوارەم: گەیشتن و حیسابی قازانج**

کاتێک باچ گەیشت، نرخی گواستنەوە (کۆست) حیساب دەکرێت و قازانجی کۆتایی دیاری دەبێت.

### 3.3 فۆرمولای حیسابکردن

```
قازانجی خاو = نرخی فرۆشتن - نرخی کڕین
قازانجی خاوێن = نرخی فرۆشتن - نرخی کڕین - کۆستی گواستنەوە
```

### 3.4 نمونەی ژمێریاری

| بابەت | بڕ | ڕوونکردنەوە |
|-------|-----|-------------|
| نرخی کڕین | $10 | نرخی کاڵا لە چین |
| قازانجی خواستراو | $15 | قازانجی کۆمپانیا |
| نرخی فرۆشتن | $25 | $10 + $15 |
| کێشی پاکەت | 1 KG | - |
| نرخی کۆستی باچ | $8/KG | نرخی کڕینی گواستنەوە |
| کۆستی گواستنەوە | $8 | 1 KG × $8 |
| **قازانجی خاو** | **$15** | $25 - $10 |
| **قازانجی خاوێن** | **$7** | $25 - $10 - $8 |

## 4. جۆری دووەم: داواکاری کڕین (Purchase Request)

### 4.1 پێناسە

داواکاری کڕین ئەو کاتەیە کە کڕیار لە پۆرتالی خۆی داوای کڕینی کاڵایەک دەکات. کڕیار لینک و زانیاری کاڵاکە دەنێرێت، کۆمپانیا نرخ دیاری دەکات، و کڕیار پەسەند دەکات.

### 4.2 پرۆسەی کارکردن

**قۆناغی یەکەم: داواکاری لە پۆرتال**

کڕیار لە پۆرتالی خۆی فۆڕمی داواکاری پڕ دەکاتەوە کە تێیدا ئەم زانیاریانە دەنێرێت:
- لینکی کاڵا
- ناوی کاڵا
- جۆر / ڕەنگ / قەبارە
- عەدەد
- وینە (ئەگەر هەبوو)
- تێبینی

**قۆناغی دووەم: نرخدانان لە کۆمپانیا**

کۆمپانیا نرخی کاڵاکە دەدۆزێتەوە و نرخی فرۆشتن دیاری دەکات. پاشان ئاگاداری بۆ کڕیار دەنێردرێت.

**قۆناغی سێیەم: پەسەندکردن لە کڕیار**

کڕیار لە پۆرتالی خۆی نرخەکە دەبینێت و دەتوانێت پەسەند بکات یان ڕەت بکاتەوە. ئەگەر پەسەند کرد، پارە لەسەر حسابی دەچێت.

**قۆناغەکانی دواتر**

هەمان پرۆسەی فول پاکیج بەردەوام دەبێت: کڕین، گواستنەوە، گەیشتن، و حیسابی قازانج.

### 4.3 فۆرمولای حیسابکردن

هەمان فۆرمولای فول پاکیج:

```
قازانجی خاو = نرخی فرۆشتن - نرخی کڕین
قازانجی خاوێن = نرخی فرۆشتن - نرخی کڕین - کۆستی گواستنەوە
```

### 4.4 بارودۆخەکانی داواکاری

| بارودۆخ | باس |
|---------|------|
| `pending_quote` | چاوەڕوانی نرخدانان |
| `quoted` | نرخ دراوە، چاوەڕوانی پەسەندکردن |
| `approved` | کڕیار پەسەندی کرد |
| `rejected` | کڕیار ڕەتی کردەوە |
| `ordered` | کاڵا کڕدرا |
| ... | (هەمان بارودۆخەکانی فول پاکیج) |

## 5. جۆری سێیەم: کڕین بە عمولە (Commission Purchase)

### 5.1 پێناسە

کڕین بە عمولە ئەو کاتەیە کە کڕیار نرخی کاڵاکە دەزانێت و کۆمپانیا تەنها خزمەتی کڕین دەکات بە بەرامبەر عمولەیەک. کڕیار خاوەنی کاڵاکەیە لە سەرەتاوە.

### 5.2 پرۆسەی کارکردن

**قۆناغی یەکەم: داواکاری و نرخدانان**

کڕیار لینکی کاڵا و نرخەکەی دەنێرێت. کۆمپانیا عمولەی خزمەتگوزاری دیاری دەکات.

**قۆناغی دووەم: پارەدانی پێشوەخت**

کڕیار پارەی کاڵا بەزیادی عمولە دەدات. ئەم پارەیە لەسەر حسابی کڕیار دەچێت و ئینڤۆیس دروست دەبێت.

**قۆناغی سێیەم: کڕین**

کۆمپانیا کاڵاکە دەکڕێت بە نرخی دیاریکراو.

**قۆناغی چوارەم: گواستنەوە**

کاڵا دەخرێتە باچ و دەنێردرێت. لەم جۆرەدا پاکەت بە جۆری `customer_owned` دروست دەبێت.

**قۆناغی پێنجەم: گەیشتن و حیساب**

کاتێک باچ گەیشت، نرخی گواستنەوە (نرخی فرۆشتن، نەک کۆست) لەسەر حسابی کڕیار دەچێت. ئەمە جیاوازە لە فول پاکیج.

### 5.3 فۆرمولای حیسابکردن

```
قازانجی عمولە = عمولەی کڕین
قازانجی باچ = (نرخی فرۆشتن - نرخی کۆست) × کێش
کۆی قازانج = قازانجی عمولە + قازانجی باچ
```

### 5.4 نمونەی ژمێریاری

| بابەت | بڕ | ڕوونکردنەوە |
|-------|-----|-------------|
| نرخی کاڵا | $10 | کڕیار دەیزانێت |
| عمولەی کڕین | $3 | خزمەتگوزاری کۆمپانیا |
| کۆی پارەدانی پێشوەخت | $13 | $10 + $3 |
| کێشی پاکەت | 1 KG | - |
| نرخی فرۆشتنی باچ | $12/KG | نرخی گواستنەوە بۆ کڕیار |
| نرخی کۆستی باچ | $8/KG | تێچووی کۆمپانیا |
| نرخی گواستنەوە (لەسەر کڕیار) | $12 | 1 KG × $12 |
| **قازانجی عمولە** | **$3** | عمولەی کڕین |
| **قازانجی باچ** | **$4** | $12 - $8 |
| **کۆی قازانج** | **$7** | $3 + $4 |

## 6. جیاوازی لە باچ

### 6.1 خاوەنداری پاکەت

هەر پاکەتێک فیڵدێکی نوێی هەیە بە ناوی `packageOwnership`:

| بەها | باس | نرخی حیسابکراو لە باچ |
|------|------|----------------------|
| `customer` | پاکەتی کڕیار (ئاسایی یان عمولە) | نرخی فرۆشتن |
| `company` | پاکەتی کۆمپانیا (فول پاکیج) | نرخی کۆست |

### 6.2 نمونەی باچ بە پاکەتی تێکەڵ

باچێک بە 12 پاکەت: 9 پاکەتی کڕیار + 3 پاکەتی کۆمپانیا (فول پاکیج)

| جۆری پاکەت | ژمارە | کێش | نرخی حیسابکراو | کۆی داهات | کۆی کۆست | قازانج |
|------------|-------|-----|----------------|-----------|----------|--------|
| کڕیار | 9 | 9 KG | $12/KG | $108 | $72 | $36 |
| کۆمپانیا | 3 | 3 KG | $8/KG | $24 | $24 | $0 |
| **کۆی گشتی** | 12 | 12 KG | - | **$132** | **$96** | **$36** |

**سەرنج گرنگ**: پاکەتە فول پاکیجەکان قازانجیان لە باچ $0 ە، چونکە بە نرخی کۆست حیساب دەکرێن. قازانجیان لە سیستەمی فول پاکیج تۆمار دەکرێت.

## 9. پۆرتالی کڕیار

### 9.1 بەشی داواکاری کڕین

کڕیار دەتوانێت لە پۆرتالی خۆی داواکاری کڕین بکات:

**فۆڕمی داواکاری:**
- لینکی کاڵا (پێویست)
- ناوی کاڵا
- جۆر / ڕەنگ / قەبارە
- عەدەد
- وینە (ئەگەر هەبوو)
- تێبینی

**لیستی داواکارییەکان:**
کڕیار دەتوانێت هەموو داواکارییەکانی خۆی ببینێت بە بارودۆخیان:
- چاوەڕوانی نرخ
- نرخ دراوە (دەتوانێت پەسەند بکات)
- پەسەندکراو
- لە ڕێگادا
- گەیشتووە

### 9.2 پیشاندانی سفارشەکان

بۆ هەر سفارشێک، کڕیار ئەم زانیاریانە دەبینێت:

**بۆ فول پاکیج و داواکاری کڕین:**
- ناوی کاڵا
- نرخی فرۆشتن
- بارودۆخ
- ڕێکەوتی چاوەڕوانکراو

**بۆ کڕین بە عمولە:**
- ناوی کاڵا
- نرخی کاڵا
- عمولە
- کۆی پارەدان
- نرخی گواستنەوە (کاتێک گەیشت)
- بارودۆخ
