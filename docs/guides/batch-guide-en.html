Creating a Batch and Scanning Packages Into It

Wazn Express — step-by-step guide for the China warehouse

This guide covers two jobs, in the order you do them. First you create a batch, which is the shipment that will carry the goods to Erbil. Then you scan packages into that batch, one by one, so the system knows exactly what is travelling.

Do these in order You cannot scan anything until a batch exists. If the scanner page shows an empty batch list, go back and create the batch first.

Before you start

  1. Open admin.waznexpress.com and sign in with your username and password.
  2. Set the language you want to work in. Click the language button at the top of the screen and choose English or 中文. Every screen in this guide is shown in English.

Part 1 — Create a batch

A batch is one shipment: one flight, or one container. Everything you scan into it travels together.

Fill in what you can, even if you are not sure Put in your best estimate for any field you are unsure about — weight, cost, dates, carrier names. Do not leave the batch unmade because a number is missing. The Erbil office checks every batch and corrects the figures when the goods arrive. An estimate you can correct is far more useful than an empty field.
  1. In the left sidebar, open Batches.
  2. Click the New Batch button at the top right. A window opens with three tabs: Basic Information, Volume & Cost and Selling Price.
  3. Batch Code — you can type your own name for this batch, in any format. If you leave it empty, the system creates a code for you. Use a name you will recognise later.
  4. Origin Warehouse and Destination — choose the China warehouse the goods are leaving from, and Iraq as the destination. Both are required.
  5. Shipping Type — choose one. This is required, and it changes which fields appear next.

  7. Shipment to warehouse — this records how the cartons physically reached the airport or port warehouse.
    • Shipment tracking numbers — type a courier tracking number and click Add. Repeat for each shipment. The Shipments count updates by itself.
    • Cartons — type how many cartons you sent in total.
    You do not need to count the pieces. Every package you scan into the batch is counted automatically.
  8. Total Shipping Cost (USD), Departure Date and Estimated Arrival Date — put in your best estimate. The dates come pre-filled; change them to the real ones if you know them.
  9. Open the Volume & Cost tab. Enter the Actual weight of the batch, and the Charged weight if the carrier charges a different figure. Cost per KG is what we pay the carrier. Estimates are fine here.
  10. Open the Selling Price tab. Price per KG is what the customer pays. Leave Special Pricing alone unless the office has told you a particular customer has an agreed rate.
  11. Click Create Batch. The new batch appears in the list with the status Preparing, and it is now ready to receive packages.
If the code is refused If you typed a batch code that already exists, the system will tell you so and nothing is saved. Change the code and click Create Batch again.

Part 2 — Scan packages into the batch

Now put the goods into the batch you just made. Each package is scanned one at a time.

  1. Get to the scanner in whichever way is quicker for you:
    • From the batch you just made — on the Batches page, click the scan button on that batch's row. The scanner opens with the batch already selected, and you can go straight to step 3.
    • From the sidebar — open Scanning, then Batch Assignment.
  2. If the batch is not already chosen, open Select a batch at the top and pick it. Nothing can be scanned until you do this — the scanner box stays greyed out and the page says Select a batch.
    Empty list? Only batches with the status Preparing or In Transit appear here. If there are none, the page says No open batches — create one on the Batches page first and gives you a Create Batch button that takes you straight there.
  3. Choose how you will read the barcode:
    • Manual — use a barcode gun, or type the number and press Enter. This is the normal way.
    • Camera — use the device camera to read the barcode.
    Leave Continuous mode switched on. The box clears itself after each scan, so you can keep scanning without touching anything.
  4. Scan the tracking number of the first package. The system finds it, adds it to the batch, and plays a sound. A green message says Added to batch.
  5. Keep scanning. Every package you add appears in the list below, newest first, and the Session stats panel on the right counts as you go: number of packages, total weight, total CBM, and how many have incomplete data.
  6. When you have finished, there is nothing to save — every scan is stored immediately. Your list stays on screen if you leave the page and come back. Use Clear only when you want to start a fresh session.

What each message means

MessageWhat happenedWhat to do
Added to batch The package is now in this batch. Nothing. Scan the next one.
Already in this batch You scanned the same package twice. Nothing. It is not added again.
Package not found This tracking number is not registered in the system at all. Register it first using Quick Register, then scan it again.
Package is in another batch The package already belongs to a different batch. A window shows you which batch. Confirm to move it here, or cancel to leave it where it is.
Incomplete data The package has no weight and no dimensions, so it cannot be priced. Best: click Go to Quick Register and add the weight. If you are in a hurry, click Continue anyway — it is added, and counted under Incomplete so it can be fixed later.
Watch the Incomplete number A package with no weight and no dimensions cannot be charged correctly. Before the batch leaves, the Incomplete count should be zero.

Part 3 — Adding the shipping details later

When you create a batch you rarely know the air waybill or the container number yet. Add them as soon as they exist — you do not need to create anything new.

  1. Open Batches and find your batch in the list.
  2. Click the edit (pencil) button on that row.
  3. Fill in whatever you now know: the Air waybill (AWB) or Container Number, the flight or vessel, the shipment tracking numbers, and the carton count.
  4. Click Save Changes.
The number becomes a link Once an air waybill or container number is saved, it appears underneath the batch code in the list as a blue link. Click it and the airline's or shipping line's own tracking page opens. If that carrier's website cannot accept the number in the address, the system copies the number for you and tells you to paste it.

Your customers see the same number on their shipment page in the customer portal, and they can click it too.
