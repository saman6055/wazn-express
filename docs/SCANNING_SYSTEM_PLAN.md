# پلانی سیستەمی سکان - Wazn Express

## پوختەی پرۆژە

دروستکردنی سیستەمێکی تەواو بۆ بەڕێوەبردنی پاکەتەکان لە کۆگا بە بەکارهێنانی تەکنەلۆژیای سکان (بارکۆد، QR، AI) کە لەگەڵ هەموو جۆرەکانی پەت بگونجێت.

---

## 1. کارەکانی کۆگا (Warehouse Operations)

### 1.1 مەبەست
بەڕێوەبردنی جووڵەی فیزیکی پاکەتەکان لە کۆگا بە سیستەمێکی دیجیتاڵی و سکان-بەیس.

### 1.2 وۆرکفلۆی کارەکان

#### 📥 **وەرگرتنی پاکەت (Package Receiving)**
**کاتی بەکارهێنان:** کاتێک پاکەت دەگاتە کۆگا

**پرۆسە:**
1. کارمەندی کۆگا کامێرا دەکاتەوە
2. بارکۆد/QR کۆدی پاکەت سکان دەکات
3. سیستەم زانیاری پاکەت پیشان دەدات (جۆر، کڕیار، تراکینگ)
4. کارمەندەکە دووگمەی "وەرگیرا" دەداتە
5. سیستەم:
   - بارودۆخ دەگۆڕێت بۆ "لە کۆگا"
   - کات و بەروار تۆمار دەکات
   - ناوی کارمەند تۆمار دەکات
   - ئاگادارکردنەوە دەنێرێت بۆ کڕیار (ئۆپشناڵ)

**داتای پێویست:**
- Package ID / Tracking Number
- Received Date & Time
- Received By (Staff ID)
- Physical Condition (Good/Damaged)
- Photos (optional)
- Weight & Dimensions (for full package)

---

#### 📦 **دانانی پاکەت لە شەلف (Shelf Assignment)**
**کاتی بەکارهێنان:** دوای وەرگرتنی پاکەت

**پرۆسە:**
1. کارمەند پاکەت سکان دەکات
2. سیستەم شوێنی بەردەست پیشان دەدات (شەلف A1، B2، هتد)
3. کارمەند شوێن هەڵدەبژێرێت یان سیستەم بە خۆکاری دیاری دەکات
4. کارمەند QR کۆدی شەلفەکە سکان دەکات بۆ دڵنیایی
5. سیستەم شوێن تۆمار دەکات

**داتای پێویست:**
- Package ID
- Shelf Location (Zone-Row-Column, e.g., A-3-12)
- Assigned Date & Time
- Assigned By (Staff ID)

**فیچەری زیرەک:**
- پێشنیاری شوێنی نزیکترین بۆ پاکەتەکانی هەمان کڕیار
- ئاگاداری کاتێک شەلف پڕە
- نەخشەی ڤیژواڵ بۆ شوێنی پاکەتەکان

---

#### 📋 **ئامادەکردنی نێردن (Shipment Preparation)**
**کاتی بەکارهێنان:** کاتێک پاکەت ئامادەیە بۆ گەیاندن

**پرۆسە:**
1. سیستەم لیستی پاکەتە ئامادەکان پیشان دەدات
2. کارمەند دەستپێدەکات بە دروستکردنی "لیستی نێردن"
3. هەر پاکەتێک سکان دەکات بۆ زیادکردن بە لیست
4. سیستەم شوێنی شەلف پیشان دەدات بۆ دۆزینەوەی خێرا
5. دوای تەواوبوون، لیستی نێردن چاپ دەکرێت
6. بارودۆخ دەگۆڕێت بۆ "ئامادەی نێردن"

**داتای پێویست:**
- Shipment ID
- Package List (IDs)
- Prepared Date & Time
- Prepared By (Staff ID)
- Delivery Method
- Estimated Delivery Date

**فیچەری زیرەک:**
- گرووپکردنی خۆکار بەپێی شار/ناوچە
- ڕێگای گونجاو بۆ کۆکردنەوەی پاکەتەکان لە کۆگا
- چاپی لەیبڵی نێردن

---

#### 🚚 **گەیاندن بە کڕیار (Customer Delivery)**
**کاتی بەکارهێنان:** کاتێک پاکەت دەردەچێت لە کۆگا

**پرۆسە:**
1. شۆفێر/کارمەند لیستی نێردن سکان دەکات
2. هەر پاکەتێک بە تاکەکەسی سکان دەکات بۆ چێککردن
3. سیستەم دڵنیایی دەکاتەوە کە هەموو پاکەتەکان سکان کراون
4. دووگمەی "دەرچوو" دەدرێت
5. بارودۆخ دەگۆڕێت بۆ "لە ڕێگادا"
6. ئاگادارکردنەوە دەنێردرێت بۆ کڕیار

**داتای پێویست:**
- Shipment ID
- Departure Date & Time
- Driver/Staff ID
- Vehicle Info (optional)
- Scanned Package Count

---

### 1.3 گونجان لەگەڵ جۆرەکانی پەت

#### 🎁 **پاکەتی ئاسایی (Regular Package)**
- وەرگرتن ✅
- دانانی شەلف ✅
- ئامادەکردنی نێردن ✅
- گەیاندن ✅

#### 📦 **فول پاکێج (Full Package)**
- وەرگرتن + تۆماری کێش و قەبارە ✅
- دانانی شەلف (شوێنی تایبەت بۆ قەبارەی گەورە) ✅
- چێککردنی کوالیتی (وێنە) ✅
- ئامادەکردنی نێردن ✅
- گەیاندن + وەرگرتنەوەی واژوو لە کڕیار ✅

#### 🛒 **داواکاری کڕین (Purchase Request)**
- وەرگرتن + بەراوردکردن لەگەڵ داواکاری ✅
- چێککردنی کوالیتی (وێنە بۆ کڕیار) ✅
- پەسەندکردنی کڕیار پێش دانانی شەلف ✅
- ئامادەکردنی نێردن ✅
- گەیاندن ✅

#### 💼 **کڕین بە عمولە (Commission)**
- وەرگرتن (سادە) ✅
- دانانی شەلف (کاتی کورت) ✅
- ئامادەکردنی نێردن ✅
- گەیاندن ✅

## 2. سکانەری AI (AI Scanner)

### 2.1 مەبەست
بەکارهێنانی هۆشی دەستکرد بۆ ناسینەوەی خۆکاری زانیاری لە وێنەکان و خێراکردنی کارەکان.

### 2.2 تایبەتمەندییەکان

#### 📸 **سکانی لەیبڵ (Label Recognition)**
**چۆنیەتی کارکردن:**
1. کارمەند وێنەی لەیبڵی پاکەت دەگرێت
2. AI زانیاریەکان دەربدەهێنێت:
   - تراکینگ نەمبەر
   - ناونیشان
   - ناوی وەرگر
   - بارکۆد
3. سیستەم بە خۆکاری فۆرم پڕدەکاتەوە

**تەکنەلۆژی:**
- OCR (Optical Character Recognition)
- Barcode/QR Detection
- Pattern Matching

**بەکارهێنان:**
- وەرگرتنی پاکەتی نوێ بەبێ تایپکردن
- نوێکردنەوەی تراکینگ بە خێرایی
- کەمکردنەوەی هەڵە

---

#### 🏷️ **ناسینەوەی کاڵا (Product Recognition)**
**چۆنیەتی کارکردن:**
1. کارمەند وێنەی کاڵا دەگرێت
2. AI کاڵا دەناسێتەوە:
   - جۆری کاڵا (کەش، جل، ئەلیکترۆنیات، هتد)
   - برەند (ئەگەر بەرچاو بێت)
   - ڕەنگ و قەبارە
3. سیستەم پێشنیاری کاتێگۆری دەکات

**تەکنەلۆژی:**
- Image Classification
- Object Detection
- Brand Recognition

**بەکارهێنان:**
- کاتێگۆریکردنی خۆکار بۆ فول پاکێج
- بەراوردکردن لەگەڵ داواکاری کڕین
- تۆماری ئینڤێنتۆری

---

#### ✅ **چێککردنی کوالیتی (Quality Check)**
**چۆنیەتی کارکردن:**
1. کارمەند وێنەی پاکەت/کاڵا دەگرێت
2. AI شیکاری دەکات:
   - زیان (شکاو، کۆڵاو، هتد)
   - پاککردنەوە
   - تەواوی (هەموو بەشەکان هەن)
3. سیستەم ڕاپۆرت دەدات (باش/ناوەند/خراپ)

**تەکنەلۆژی:**
- Defect Detection
- Image Comparison
- Anomaly Detection

**بەکارهێنان:**
- چێککردنی پاکەت کاتی وەرگرتن
- دۆکیومێنتکردنی زیان بۆ کلەیم
- دڵنیایی لە کوالیتی پێش نێردن بۆ کڕیار

---

#### 📊 **ئەنالیزی وێنە (Image Analysis)**
**چۆنیەتی کارکردن:**
1. سیستەم وێنەکان کۆدەکاتەوە
2. AI ئەنالیز دەکات:
   - جۆرە باوەکانی کاڵا
   - پرۆبلەمە دووبارەبووەکان
   - ترێندی کوالیتی
3. ڕاپۆرتی ئاماری دروست دەکات

**بەکارهێنان:**
- بەرزکردنەوەی کوالیتی خزمەتگوزاری
- ناسینەوەی فرۆشیارە پرۆبلەمداران
- باشترکردنی پرۆسەکان

---

## 3. سکانەری زیرەک (Smart Scanner)

### 3.1 مەبەست
سکانی خێرا و کارا بۆ بەڕێوەبردنی کۆمەڵە پاکەت بە یەکجاری.

### 3.2 تایبەتمەندییەکان

#### 🔄 **سکانی کۆمەڵە (Batch Scanning)**
**چۆنیەتی کارکردن:**
1. کارمەند مۆدی "سکانی کۆمەڵە" چالاک دەکات
2. بە بەردەوامی بارکۆدەکان سکان دەکات (بەبێ دووگمە لێدان)
3. سیستەم هەر سکانێک بە خۆکاری زیاد دەکات بە لیست
4. دەنگی بیپ بۆ هەر سکانێک (سەرکەوتوو/دووبارە/هەڵە)
5. لە کۆتاییدا، دووگمەی "تەواو" دەدرێت

**فیچەرەکان:**
- سکانی خێرا (< 1 چرکە بۆ هەر ئایتم)
- ناسینەوەی خۆکاری دووبارەبوون
- کاونتەری ڕاستەوخۆ
- ئەندوو/ڕیدوو بۆ لابردنی سکانی هەڵە

**بەکارهێنان:**
- وەرگرتنی چەند پاکەتێک پێکەوە
- ئامادەکردنی لیستی نێردن
- چێککردنی ئینڤێنتۆری

---

#### 📦 **سکانی باچ (Batch Processing)**
**چۆنیەتی کارکردن:**
1. کارمەند باچێک هەڵدەبژێرێت لە سیستەم
2. سیستەم لیستی پاکەتەکانی باچ پیشان دەدات
3. کارمەند هەر پاکەتێک سکان دەکات
4. سیستەم چێک مارک دەکات (✓) و ڕەنگ دەگۆڕێت (سەوز)
5. کاتێک هەموو پاکەتەکان سکان کران، باچ تەواو دەبێت

**فیچەرەکان:**
- پرۆگرێس بار (5/20 سکان کراوە)
- لیستی ڤیژواڵ لەگەڵ چێک مارک
- ئاگاداری بۆ پاکەتی ون
- فیلتەر بۆ پاکەتە سکان نەکراوەکان

**بەکارهێنان:**
- پرۆسێسکردنی باچی گەیشتوو لە چین
- چێککردنی تەواوی باچ پێش نێردن
- ئینڤێنتۆری کۆگا

---

#### ✔️ **چێککردنی لیست (List Verification)**
**چۆنیەتی کارکردن:**
1. سیستەم لیستی چاوەڕوان (expected list) لۆد دەکات
2. کارمەند پاکەتە فیزیکییەکان سکان دەکات
3. سیستەم بەراورد دەکات:
   - ✅ سەوز: لە لیستدایە و سکان کراوە
   - ⚠️ سەر: لە لیستدایە بەڵام سکان نەکراوە
   - ❌ سوور: سکان کراوە بەڵام لە لیستدا نییە
4. ڕاپۆرتی فەرق پیشان دەدات

**فیچەرەکان:**
- بەراوردی ڕاستەوخۆ
- ڕاپۆرتی تەواوی/ون/زیادە
- ئیکسپۆرتی ڕاپۆرت (PDF/Excel)

**بەکارهێنان:**
- چێککردنی نێردراوەکان لە فرۆشیار
- دڵنیایی لە تەواوی پاکەتەکان پێش نێردن
- ئۆدیتی ئینڤێنتۆری

---

#### 📊 **ڕاپۆرتی سکان (Scan Report)**
**زانیاری پیشاندراو:**
- کۆی سکانەکان (ئەمڕۆ/ئەم هەفتەیە/ئەم مانگە)
- سکان بەپێی جۆری پاکەت
- سکان بەپێی کارمەند
- کاتی خێراترین/خاوترین سکان
- ڕێژەی هەڵە

**چارتەکان:**
- لاین چارت: سکانی ڕۆژانە
- پای چارت: سکان بەپێی جۆری پاکەت
- بار چارت: سکان بەپێی کارمەند

**بەکارهێنان:**
- هەڵسەنگاندنی کارایی
- ناسینەوەی بۆتڵنێک
- پلاندانانی ستاف

## 5. ستراکچەری دەیتابەیس (Database Structure)

### 5.1 خشتەی سکانەکان (scans table)

```sql
CREATE TABLE scans (
  id INT PRIMARY KEY AUTO_INCREMENT,
  scanType ENUM('receive', 'shelf', 'prepare', 'deliver', 'quality', 'inventory'),
  packageId INT,
  packageType ENUM('regular', 'full_package', 'purchase_request', 'commission'),
  batchId INT NULL,
  scannedBy INT, -- staff user ID
  scannedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  location VARCHAR(50) NULL, -- shelf location
  notes TEXT NULL,
  aiData JSON NULL, -- AI recognition results
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 5.2 خشتەی شەلفەکان (shelves table)

```sql
CREATE TABLE shelves (
  id INT PRIMARY KEY AUTO_INCREMENT,
  shelfCode VARCHAR(20) UNIQUE, -- e.g., A-3-12
  zone VARCHAR(10), -- A, B, C
  row INT,
  column INT,
  capacity INT DEFAULT 10,
  currentCount INT DEFAULT 0,
  qrCode TEXT, -- QR code for shelf
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 5.3 خشتەی لیستی نێردن (shipments table)

```sql
CREATE TABLE shipments (
  id INT PRIMARY KEY AUTO_INCREMENT,
  shipmentCode VARCHAR(50) UNIQUE,
  packageIds JSON, -- array of package IDs
  preparedBy INT, -- staff user ID
  deliveredBy INT NULL, -- driver user ID
  status ENUM('preparing', 'ready', 'in_transit', 'delivered'),
  preparedAt TIMESTAMP,
  deliveredAt TIMESTAMP NULL,
  notes TEXT NULL,
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 5.4 خشتەی AI ئەنالیز (ai_analyses table)

```sql
CREATE TABLE ai_analyses (
  id INT PRIMARY KEY AUTO_INCREMENT,
  packageId INT,
  analysisType ENUM('label', 'product', 'quality'),
  imageUrl TEXT,
  results JSON, -- AI recognition results
  confidence DECIMAL(5,2), -- 0.00 to 100.00
  analyzedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 8. UX/UI دیزاین

### 8.1 پرینسیپەکان
- **سادەیی:** UI زۆر سادە بۆ بەکارهێنانی خێرا
- **خێرایی:** کەمترین کلیک بۆ هەر کارێک
- **فیدباکی بینراو:** ڕەنگ، دەنگ، ڤایبرەیشن بۆ هەر کردار
- **ڕێسپۆنسیڤ:** کاردەکات لەسەر مۆبایل و تابلێت
- **دارک مۆد:** بۆ کارکردن لە کۆگای تاریک

### 8.2 ڕەنگەکان
- **سەوز (Success):** سکانی سەرکەوتوو، پاکەتی تەواو
- **سەر (Warning):** پاکەتی ون، ئاگاداری
- **سوور (Error):** سکانی هەڵە، پرۆبلەم
- **شین (Info):** زانیاری، یارمەتی
- **ڕەش/سپی:** بنەڕەت

### 8.3 دەنگەکان
- **بیپ کورت:** سکانی سەرکەوتوو
- **بیپ درێژ:** سکانی دووبارە
- **بیپ دوو جار:** سکانی هەڵە
- **بیپ موزیکاڵ:** تەواوبوونی کار

## 9. سێکیوریتی و پەرمیشن (Security & Permissions)

### 9.1 ڕۆڵەکان
- **ئەدمین:** دەسەڵاتی تەواو
- **مانێجەری کۆگا:** بەڕێوەبردنی هەموو کارەکان
- **کارمەندی کۆگا:** سکان و کارەکانی ڕۆژانە
- **شۆفێر:** تەنها سکانی دەرچوون/گەیاندن
- **بینەر:** تەنها بینینی ڕاپۆرتەکان

### 9.2 لۆگ و ئۆدیت
- هەموو سکانێک تۆمار دەبێت لەگەڵ کات و کارمەند
- ناتوانرێت سکانێک بسڕدرێتەوە (تەنها ئەدمین)
- ڕاپۆرتی گۆڕانکارییەکان (audit log)

## 10. KPIs و میتریکس (Key Performance Indicators)

### 10.1 میتریکسەکانی سەرەکی
- **سکان پێر ئاوەر:** ژمارەی سکان لە هەر کاتژمێرێک
- **ئەکیوراسی ڕەیت:** ڕێژەی سکانی ڕاست
- **ئەڤەرێج سکان تایم:** کاتی ناوەندی بۆ هەر سکانێک
- **پاکەج پرۆسێسینگ تایم:** کات لە وەرگرتنەوە تا نێردن
- **شەلف یوتیلایزەیشن:** ڕێژەی بەکارهێنانی شەلفەکان

### 10.2 ئامانجەکان
- سکانی 200+ پاکەت لە ڕۆژێکدا
- ڕێژەی هەڵە < 1%
- کاتی ناوەندی < 3 چرکە بۆ هەر سکانێک
- کاتی پرۆسێس < 24 کاتژمێر بۆ هەر پاکەتێک
