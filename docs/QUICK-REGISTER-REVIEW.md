# پشکنینی تۆماری خێرا — چۆنیەتی کارکرد و هەڵەکان

## ١. ڕێڕەوی تۆمارکردن (Flow)

### قۆناغەکانی بەکارهێنەر

| # | قۆناغ | وەسف |
|---|--------|------|
| 1 | **تراکینگ** | بەکارهێنەر تراکینگ نەمبەر دەنووسێت. دەتوانێت کلیکی گەڕان بکات یان دوای نووسین Enter بدات. |
| 2 | **گەڕان (ئارەزوومەندانە)** | API `scanning.searchTrackingAllTypes` تراکینگەکە دەگەڕێت لە: full_package، commission، پاکەتی پێشتر تۆمارکراو. ئەگەر بدۆزرێتەوە کڕیار خۆکار پڕ دەبێتەوە؛ ئەگەر وەک «پاکەت» بدۆزرێتەوە تۆمارکردنی دووبارە قەدەغە دەبێت. |
| 3 | **کڕیار** | هەڵبژاردنی کڕیار (گەڕان بە کۆد/ناو) یان **بێ خاوەن** (دۆگمەی ئامادە). |
| 4 | **کۆگا** | هەڵبژاردنی کۆگا (لیستی کۆگاکان)؛ بنەڕەت یەکەم کۆگا. |
| 5 | **جۆری گواستنەوە** | ئاسمانی یاسایی / نایاسایی / دەریایی. |
| 6 | **کێش (KG)** | کێشی پاکەت. |
| 7 | **قەبارە (ئارەزوومەندانە)** | بۆ کێشی قەبارەیی: درێژی، پانی، بەرزی (cm) یان CBM ڕاستەوخۆ بۆ دەریایی. |
| 8 | **باچ / جۆری بەرهەم (ئارەزوومەندانە)** | لە لیستەکان هەڵدەبژێردرێت. |
| 9 | **تۆمار** | کلیکی «تۆمار (Enter)» یان **Enter** — فۆرم نێردراوە بۆ `packages.register`. |

### شتە پێویستەکان (لە کلایەنت)

- **تراکینگ نەمبەر** — نابێت بەتاڵ بێت.
- **کڕیار** — یان کڕیار هەڵبژێردرابێت یان **بێ خاوەن** چالاک بێت.
- **کۆگا** — بەکارهێنەر کۆگا لە لیست هەڵدەبژێرێت (سێکشنی «٣. کۆگا»)؛ بنەڕەت یەکەم کۆگایە. ئەگەر هیچ کۆگایەک نەبێت، تۆمار قەدەغە دەبێت.

باچ، جۆری بەرهەم، وەرگ، قەبارە، وێنە **ئارەزوومەندانن** بۆ تۆمارکردن.

## ٢. چۆنیەتی تۆمارکردنی پاکەت (سێرڤەر)

دوای کلیکی تۆمار یان Enter، کلایەنت **`packages.register`** (tRPC mutation) بانگهێشت دەکات بەم داتایە:

- `customerId` (ئەگەر بێ خاوەن نەبێت)
- `isUnclaimed`
- `originWarehouseId` — **کۆگای هەڵبژێردراو** (state `originWarehouseId`؛ بنەڕەت یەکەم کۆگا)؛ ئەگەر کۆگا هەڵنەبژێردرابێت لە کلایەنت قەدەغە کراوە
- `trackingNumber`, `weightKg`, `lengthCm`, `widthCm`, `heightCm`, `volumeCbm` (بۆ دەریایی)
- `shippingType`: `air_regular` | `air_irregular` | `sea`
- `batchId`, `categoryId` (ئارەزوومەندانە)
- `description`, `photos`
- `fullPackageOrderId` — ئەگەر تراکینگ لە full_package بدۆزرێتەوە

**لە سێرڤەر (packages.router.ts):**

1. **کۆگا** — `getWarehouseById(originWarehouseId)`؛ ئەگەر نەبێت → `کۆگا نەدۆزرایەوە...`
2. **باچ** — ئەگەر `batchId` بنێردرابێت، `getBatchById`؛ ئەگەر نەبێت → `گرووپ/بەچ نەدۆزرایەوە...`
3. **جۆری بەرهەم** — ئەگەر `categoryId` بنێردرابێت، `getProductCategoryById`؛ ئەگەر نەبێت → `جۆری بەرهەم نەدۆزرایەوە...`
4. **تراکینگ دووبارە** — `getPackageByTrackingNumber`؛ ئەگەر پێشتر تۆمار کرابێت → `ئەم تراکینگە پێشتر تۆمار کراوە...`
5. **کڕیار** — ئەگەر `customerId` هەبێت و بێ خاوەن نەبێت، `getCustomerById`؛ ئەگەر نەبێت → `کڕیار نەدۆزرایەوە...`
6. **نرخ** — لە وڵات و قەبارە/کێش نرخی تەخمینی دەگیرێت (بۆ پاکەتی عادی، نەک بێ خاوەن).
7. **دروستکردنی پاکەت** — `createPackage`؛ کۆدی پاکەت بە `getNextPackageCode` یان `getNextUnclaimedPackageCode` دروست دەبێت؛ ئەگەر duplicate (کۆدی یەکسان) بێت تا ٤ جار دووبارە هەوڵ دەدرێت.
8. **Audit log** — `register_package` تۆمار دەکرێت.

ئەگەر هەڵەی داتابەیس (وەک ER_DUP_ENTRY بۆ تراکینگ) بێت، سێرڤەر وەک **CONFLICT** یان **هەڵەی داتابەیس** دەگەڕێنێتەوە.

## ٣. کاتێک هەڵە دەدات (هەڵەکان)

### لە کلایەنت (پێش ناردن)

| هەڵە | نامە (toast) |
|------|----------------|
| تراکینگ بەتاڵە | «تکایە تراکینگ نەمبەر داخل بکە» |
| تراکینگ پێشتر وەک پاکەت تۆمار کراوە (`foundOrder.source === "package"`) | «ئەم تراکینگە پێشتر تۆمار کراوە! ناتوانرێت دووبارە تۆماری بکەیت» |
| نە کڕیار هەڵبژێردرابێت نە بێ خاوەن | «تکایە کڕیارێک هەڵبژێرە یان بێ خاوەن دیاری بکە» |
| هیچ کۆگایەک نییە یان هەڵنەبژێردراوە (`!selectedWarehouse`) | «تکایە کۆگایەک هەڵبژێرە» |

### دوای ناردن — هەڵەکانی سێرڤەر (onError)

سێرڤەر زۆربەی هەڵەکان بە **کوردی** دەگەڕێنێتەوە؛ کلایەنت ئەو نامانە وەک **toast.error** پیشان دەدات:

| کۆدی سێرڤەر / مەرج | نامەی نیشاندراو |
|----------------------|------------------|
| کۆگا نەدۆزرایەوە (NOT_FOUND) | «کۆگا نەدۆزرایەوە. تکایە کۆگایەک زیاد بکە یان هەڵبژێرە.» |
| گرووپ/بەچ نەدۆزرایەوە | «گرووپ/بەچ نەدۆزرایەوە. تکایە بەچێکی دروست هەڵبژێرە...» |
| جۆری بەرهەم نەدۆزرایەوە | «جۆری بەرهەم نەدۆزرایەوە...» |
| تراکینگ پێشتر تۆمار کراوە (CONFLICT) | «ئەم تراکینگە پێشتر تۆمار کراوە. ناتوانرێت دووبارە تۆماری بکەیت.» |
| کڕیار نەدۆزرایەوە | «کڕیار نەدۆزرایەوە. کڕیارێکی تر هەڵبژێرە یان بێ خاوەن دیاری بکە.» |
| نامەی ئینگلیزی "Warehouse not found" | «کۆگا نەدۆزرایەوە. تکایە لە ڕێکخستنەکان کۆگا زیاد بکە.» |
| نامەی "Customer not found" | «کڕیار نەدۆزرایەوە...» |
| duplicate / CONFLICT / تۆمار کراوە | «ئەم تراکینگە پێشتر تۆمار کراوە.» |
| هەر نامەیەکی تری کوردی (کۆگا، کڕیار، گرووپ، جۆری، تکایە، تراکینگە پێشتر، هەڵەی داتابەیس) | هەمان نامەی سێرڤەر |
| هەڵەیەکی تر | «هەڵەیەک ڕوویدا. دووبارە هەوڵ بدەرەوە.» یان نامەی هەڵەکە |

### هەڵەی پەیوەندی داتا (لیستەکان)

ئەگەر یەکێک لە API‑ەکانی **customers.list**، **batches.list**، **warehouses.list**، **productCategories.list**، **packages.stats** شکست بخات:

- **بانێری زەرد** لە سەرەوەی فۆرم دەردەکەوێت: «پەیوەندی بە هەندێک داتا نەگەیشت. دەتوانیت دووبارە هەوڵ بدەیتەوە یان بە بەتاڵی بەردەوام بەیت.»
- دوگمەی **«دووبارە هەوڵ بدە»** هەموو ئەو query‑انە دووبارە دەکاتەوە.
- فۆرم **ناوەستێت**؛ دەتوانیت بە لیستە بەتاڵەکان تۆمار بکەیت (وەک بە بەتاڵی باچ/جۆر).

### هەڵە لە گەڕانی تراکینگ

- **UNAUTHORIZED** → «تکایە چوونەژوورەوە بکەرەوە»
- هەڵەیەکی تر → «هەڵە لە گەڕاندا»

## ٤. کۆدی گرنگ

| شوێن | ڕۆڵ |
|------|-----|
| `client/src/pages/QuickRegister.tsx` | فۆرم، validation، گەڕانی تراکینگ، بانگهێشتی `packages.register`، بانێری هەڵە و «دووبارە هەوڵ بدە» |
| `server/routers/packages.router.ts` → `register` | پشکنینی کۆگا، باچ، جۆر، تراکینگ، کڕیار؛ نرخ؛ `createPackage`؛ audit log |
| `server/db/packages.db.ts` | `createPackage`, `getNextPackageCode`, `getNextUnclaimedPackageCode`, `getPackageByTrackingNumber` |

## ٥. کورتە

- **تۆمارکردن:** تراکینگ + کڕیار (یان بێ خاوەن) + کۆگا (یەکەم کۆگا) پێویستن؛ باچ و جۆر ئارەزوومەندانن.
- **هەڵەکان:** لە کلایەنت پێش ناردن (تراکینگ بەتاڵ، کڕیار، کۆگا، تراکینگ دووبارە)؛ لە سێرڤەر دوای ناردن (کوردی یان ئینگلیزی وەک toast). ئەگەر لیستەکان شکست بخەن، بانێری زەرد و «دووبارە هەوڵ بدە» پیشان دەدرێت و فۆرم بەردەوام دەبێت.
