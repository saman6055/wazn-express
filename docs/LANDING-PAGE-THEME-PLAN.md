# پلانی پرۆفیشناڵ — پەرەی یەکەمی ویبسایت و ڕووکاری لاندینگ
## Professional Plan: Landing (First) Page & Theme/Skin from Settings

ئەم پلانە ڕێکخستنێکی تەواو دەدات بۆ **پەرەی یەکەم (لاندینگ)**ی ویبسایت و ئەوەی لە **سیتینگ** بتوانین **ڕووکار/سکینی** ئەو پەرەیە بگۆڕین، بەبێ ئەوەی فەنکشنی پەرەکە تێکبشکێنێت.

---

## ١. وەسفی ئەوەی ئێستا هەیە (Current State)

### ١.١ پەرەی یەکەم (Home / Landing)
- **فایل:** `client/src/pages/Home.tsx`
- **شوێن:** پەرەی سەرەکی کە بەکارهێنەر پێش چوونەژوورەوە دەیبینێت.
- **سەکشنەکان:**
  - Header (لۆگۆ، ناو، ناوەڕۆکی نێڤیگەیشتن، دووگمەکانی پۆرتاڵ و staff login)
  - Hero (ناونیشان، دەق، Quick Track، دووگمەکانی CTA، کارتی تراکینگ)
  - Stats (ژمارەکان: پاکەت، وڵات، کڕیار، ڕازیبوون)
  - Services (ئاسمان، دەریا، کۆنسۆڵیدەیشن، دابەشکردنی ناوخۆیی، بیمە، پشتگیری ٢٤/٧)
  - Features (تراکینگی ڕاستەوخۆ، ژمارەدان، کاتی چاوەڕوان، VIP، پاراستنی داتا، سکانەری خێرا)
  - CTA (داوای هەڵبژاردن)
  - Contact (براند، لینکە خێراکان، پەیوەندی)
  - Footer

### ١.٢ ڕووکار ئێستا
- **تەنها یەک ڕووکار:** تاریک (Dark) — `bg-slate-900`, `slate-800`, `amber/orange` بۆ accent.
- **هیچ هەڵبژاردنێک نییە:** ڕووکار هەر وەک ئێستا هاردکۆد کراوە؛ گۆڕینی لە سیتینگ نییە.
- **پۆرتاڵی کڕیار:** لە سیتینگدا ڕووکاری پۆرتاڵ (کلاسیک / مۆدێرن) هەیە و لە `Settings.tsx` تابی «ڕووکاری پۆرتاڵی کڕیار» دەگۆڕێت؛ پەرەی یەکەم لەم سیستەمەدا نییە.

### ١.٣ سیستەمی ڕووکاری ئێستا لە پرۆژەکە
- **ThemeContext:** `light` / `dark` بۆ داشبۆرد و پۆرتاڵ (ئارەزووی بەکارهێنەر).
- **PortalThemeContext:** `classic` / `modern` بۆ layoutی پۆرتاڵ؛ لە سیتینگ (`portalTheme`) دەخوێنرێتەوە و لە `trpc.public.getPortalTheme` دێت.
- **Home.tsx:** هیچ context یان API ی ڕووکار بەکارناهێنێت؛ هەموو رەنگ و background هاردکۆدن.

---

## ٢. ئامانجەکان (Goals)

1. **پەرەی یەکەم بە شێوەیەکی پرۆفیشناڵ بمێنێتەوە** — هەموو سەکشن و فەنکشنەکانی ئێستا جێبەجێبن.
2. **ڕووکار/سکینی پەرەی یەکەم لە سیتینگ بگۆڕێت** — وەک ڕووکاری پۆرتاڵ، بە هەڵبژاردنی ئەدمین لە سیتینگ.
3. **چەند ڕووکارێک بەردەست بێت** — لانیکەم تاریک (ئێستا) و ڕووناک؛ ئەگەر گونجاو بێت ڕووکاری سێیەم (وەک Ocean/شین).
4. **یەکگرتوویی لەگەڵ پرۆژە** — بەکارهێنانی هەمان سیستەمی سیتینگ (key/value)، API ی public، و شێوازی UI ی سیتینگ وەک تابی ڕووکاری پۆرتاڵ.
5. **لۆگۆ، ناونیشان، ژمارە مۆبایل و هەموو تایبەتمەندییەکان لە ڕێکخستنەکانی سیستەم وەربگیرێت** — هەموو داتای پەیوەندی بە کۆمپانیا (لۆگۆ، ناو، phone، phone2، email، address، website) لە سیتینگی «زانیاری کۆمپانیا» (company_info) دێن؛ هیچ هاردکۆد و هیچ ڕێکخستنێکی دووبارە بۆ پەرەی لاندینگ نەبێت؛ یەک سەرچاوەی ڕاست.

## ٣. ڕووکارە پێشنیارکراوەکان (Theme Options)

| ناو (کوردی) | ناو (EN)   | ID        | وەسف |
|-------------|------------|-----------|------|
| تاریک       | Dark       | `dark`    | ڕووکاری ئێستا — slate-900، amber/orange؛ گونجاو بۆ بینینی نایتر. |
| ڕووناک     | Light      | `light`   | پسپۆڕی سپی/خۆڵەمێش ڕووناک؛ سەرنجڕاکێش بۆ ڕۆژ. |
| ئۆشن (ئەگەر دەتەوێت) | Ocean  | `ocean`   | شین/تەڵاو — گونجاو بۆ براندی لۆژستیک و ئاسمان/دەریا. |

**Default:** `dark` (وەک ئێستا)، بۆ ئەوەی هیچ گۆڕانکارییەکی بینراو لە جێبەجێکردنی یەکەمدا نەبێت.

## ٤. تەکنیکی جێبەجێکردن (Technical Implementation)

### ٤.١ Backend
- **کلیلی سیتینگ:** `landingTheme` (وەک `portalTheme`).
- **API ی public:** زیادکردنی `getLandingTheme` لە هەمان شوێنی `getPortalTheme` (وەک لە `server/routers/admin.router.ts` یان شوێنی `public` procedures) بۆ خوێندنەوەی `landingTheme`؛ بەبێ چوونەژوورەوە بەردەست بێت بۆ `Home.tsx`.
- **نووسین:** لە سیتینگدا بە `trpc.settings.set` کلیلی `landingTheme` و تەنها value یەکێک لە `dark` | `light` | `ocean` دەنووسرێت.

### ٤.٢ Frontend — خوێندنەوە و بەکارهێنان
- **Context ی نوێ (پێشنیار):** `LandingThemeContext` — وەک `PortalThemeContext`، بە `trpc.public.getLandingTheme.useQuery()` و state ی `landingTheme`؛ Provider لە `App.tsx` دەبێت دەوری ئەو ڕێگایە بێت کە `Home` تێدا دەڕوات (یەکسانە بۆ هەموو ئەپەکە یان تەنها بۆ route ی `/`).
- **جێگرەوە:** لە `Home.tsx` دا ڕاستەوخۆ `useQuery(trpc.public.getLandingTheme)` بەکارهێنرێت بێت Context؛ ئەگەر تەنها لە Home بەکار دەهێنرێت، ئەمە سادەترە.
- **فایلەکانی دەستکاری:**  
  - `client/src/pages/Home.tsx` — وەرگرتنی ڕووکار و جێبەجێکردنی کلاسەکانی رەنگ/پسپۆڕ بەپێی `landingTheme`.  
  - `client/src/pages/Settings.tsx` — زیادکردنی بەشی «ڕووکاری پەرەی یەکەم (لاندینگ)» و هەڵبژاردنی ڕووکار (کارتی پیشاندان وەک Portal Theme).

### ٤.٣ ڕووکاری پەرە (CSS / Tailwind)
- **شێواز:** لە `Home.tsx` دا بە جیاکردنەوەی کلاسەکان بەپێی `landingTheme`:
  - **Dark:** ئێستا — `bg-slate-900`, `text-white`, `amber/orange` gradients, `border-white/10`, `bg-white/5`, etc.
  - **Light:** `bg-slate-50` یان `bg-white`, `text-slate-900`, `border-slate-200`, accent وەک `amber-600` یان `blue-600`؛ هەمان layout و کامپۆنێنت.
  - **Ocean (ئەگەر هەبێت):** `bg-slate-900` یان شینە تاریک، accent شین/سەوز؛ هەمان پرینسیپ.
- **ئەنیمەیشن و بلور:** هەمان `blur-3xl`, `animate-pulse` و structure بەجێبهێڵین؛ تەنها رەنگەکان دەگۆڕین.
- **دڵنیایی RTL:** لە هەموو ڕووکارەکاندا RTL و spacing وەک ئێستا بمێنێتەوە.

### ٤.٤ سیتینگ (UI)
- **شوێن:** لە پەڕەی **Settings**، لە تابی «ڕووکاری پۆرتاڵی کڕیار» نزیک یان لە **تابێکی نوێ** وەک «پەرەی یەکەم / لاندینگ» یان لە یەک تابی «ڕووکارەکان» لەگەڵ پۆرتاڵ.
- **کۆمپۆنێنت:** وەک `PortalThemeSettings` — کارت بۆ هەر ڕووکارێک (ناو، وەسف، preview ی بچووک)، کلیک بۆ هەڵبژاردن، `settings.set({ key: 'landingTheme', value: themeId })`، دوای سەرکەوتوویی toast و ئەگەر پێویست بێت reload یان refetch بۆ پەرەی یەکەم.
- **زمانەکان (i18n):** نوێکردنەوەی `client/src/locales/*.json` بۆ ناونیشانی «ڕووکاری پەرەی یەکەم» و ناوەکانی ڕووکارەکان (تاریک، ڕووناک، ئۆشن).

## ٥. قۆناغەکانی جێبەجێکردن (Implementation Phases)

| قۆناغ | کار | مەودایە کات (تەخمینی) |
|-------|-----|-------------------------|
| **١** | Backend: زیادکردنی `getLandingTheme` (public) و پشتگیری `landingTheme` لە DB/settings | ٠.٥ ڕۆژ |

## ٦. پلانی وردتری پەرەی یەکەم (UI/UX)

- **سەکشنەکان دەمێننەوە:** Header, Hero, Stats, Services, Features, CTA, Contact, Footer — هیچ سەکشنێک نەدەسڕێتەوە.
- **فەنکشنەکان:** Quick Track، دووگمەکانی پۆرتاڵ و staff، لینکەکان، فۆرم و CTA — هەر وەک ئێستا.
- **تەنها گۆڕان:** رەنگ و پسپۆڕی background و border و text و accent بەپێی `landingTheme`؛ لە سیتینگدا هەڵبژێردراو دەگۆڕێت.
- **پرۆفیشناڵی:** هەمان spacing، فۆنت، سایزی دووگمە، و layout؛ contrast و خوێندنەوە لە ڕووناک و تاریک و ئۆشندا چەک بکرێت.

## ٧. کورتە (Summary)

- **ئێستا:** پەرەی یەکەم تەنها ڕووکاری تاریک هەیە و لە سیتینگدا ناگۆڕێت.
- **دوای جێبەجێکردن:** لە سیتینگ بەشی «ڕووکاری پەرەی یەکەم» دەبێت؛ هەڵبژاردنی تاریک / ڕووناک (و ئۆشن ئەگەر زیاد بکرێت)؛ پەرەی یەکەم بە هەمان سەکشن و فەنکشن، بەڵام بە ڕووکاری هەڵبژێردراو نمایش دەدرێت.
- **تەکنیک:** `landingTheme` لە settings، `getLandingTheme` public API، خوێندن لە Home، نووسین لە Settings؛ رەنگەکان لە `Home.tsx` بەپێی theme جیادەکرێتەوە.

ئەگەر پێت باشە، دەتوانین یەکەم قۆناغ (Backend + API) دەستپێبکەین و دواتر Frontend و Settings و i18n تەواو بکەین.
