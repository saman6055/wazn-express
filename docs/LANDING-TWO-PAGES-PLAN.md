# پلانی پرۆفیشناڵ — دوو پەرەی لاندینگی تەواو جیاواز
## Professional Plan: Two Completely Different Landing Pages

ئەم پلانە ڕێکخستنێکی تەواو دەدات بۆ **دوو پەرەی لاندینگی تەواو جیاواز** کە لە سیتینگ بتوانین هەڵیانبژێرین. جیاوازی لە **ڕووکار/رەنگ** نییە؛ جیاوازی لە **دیزاین، ڕیزبەندی، سەکشنەکان و شێوازی پەرەکە** دەبێت — وەک دوو ماڵپەڕی سەرەکی جیاواز.

---

## ١. وەسفی ئەوەی ئێستا هەیە (Current State)

- **پەرەی یەکەم:** تەنها یەک **دیزاینی پەرە** هەیە (`Home.tsx`) — هەمان سەکشنەکان (Header → Hero → Stats → Services → Features → CTA → Contact → Footer) و تەنها **ڕووکار (تاریک/ڕووناک/ئۆشن)** لە سیتینگ دەگۆڕێت.
- **گۆڕان:** ئێستا دەتوانین ڕووکار بگۆڕین؛ **شێواز و ژێرەکانی پەرە** هەر یەکێکن و ناگۆڕێن.

---

## ٢. ئامانج (Goal)

دروستکردنی سیستەمێک کە **دوو پەرەی لاندینگی تەواو جیاواز** پێشکەش بکات:

1. **پەرەی یەکەم (کلاسیک / پڕ):** ئەو دیزاینەی ئێستا — هەموو سەکشنەکان، دوو ستونی Hero، ئامار، خزمەتگوزارییەکان، تایبەتمەندییەکان، CTA، پەیوەندی، Footer.
2. **پەرەی دووەم (جیاواز):** پەرەیەکی **تەواو جیاواز** — ڕیزبەندی جیاواز، سەکشنە جیاوازەکان یان کەمتر/زیاتر، شێوازی بینراو جیاواز (وەک مینیماڵ، یان split-screen، یان single-flow)، بەبێ ئەوەی هیچ لە پەرەی یەکەم کۆپی بکرێت.

لە **سیتینگ** ئەدمین هەڵبژاردن دەکات کە **کام پەرە** وەک پەرەی سەرەکی پیشان بدرێت (تەنها یەکێک لە دووەکان لە هەمان کاتدا چالاکە).

---

## ٣. ناساندنی دوو پەرە (Two Page Variants)

| ناو (کوردی) | ID (تەقنیکی) | وەسفی کورت |
|-------------|----------------|-------------|
| **پەرەی پڕ / کلاسیک** | `classic` | دیزاینی ئێستا — هەموو سەکشنەکان، Hero دوو ستون، ئامار، خزمەتگوزاری، تایبەتمەندی، CTA، پەیوەندی، Footer. گونجاو بۆ کۆمپانیایەکی پڕ خزمەتگوزاری. |
| **پەرەی مینیماڵ / سادە** | `minimal` | پەرەیەکی کەمتر و جیاواز — سەنتەرکراوی سەر یەک ستون، Hero گەورە + تراکینگ + دووگمەکانی سەرەکی؛ بەشێکی کورت بۆ خزمەتگوزاری یان پەیوەندی؛ بێ ئامار یان کەم؛ Footer کورت. گونجاو بۆ بینینی سادە و خێرا. |

**Default:** `classic` — بۆ ئەوەی هیچ گۆڕانکارییەکی بینراو لە بەکارهێنەرانی ئێستادا نەبێت.

---

## ٤. جیاوازی ڕوون لە نێوان دوو پەرەدا

### ٤.١ پەرەی یەکەم (Classic) — ئێستا
- **سەکشنەکان:** Header → Hero (دوو ستون، چەپ دەق + ڕاست کارتی تراکینگ) → Stats (٤ کارت) → Services (٦ کارت) → Features (٦ ئایتم) → **(ئەگەر چالاک بکرێت)** بەشی بلۆگ (نوێترین بابەتەکان) و بەشی ستاف/تیم (تیمی ئێمە — داتاکە لە ئەدمین دەنووسرێت) → CTA (بەشی ناوەڕۆک) → Contact (٤ ستون) → Footer.
- **ڕیزبەندی:** بەرزی زۆر، scroll درێژ.
- **تراکینگ:** لە Hero و لە Header نەبێت؛ دووگمەکانی پۆرتاڵ و staff لە Header و Hero.

### ٤.٢ پەرەی دووەم (Minimal) — پێشنیارکراو
- **سەکشنەکان:** Header (هەمان فەنکشن بەڵام شێوازێکی کەمتر یان سادەتر) → Hero گەورە (سەنتەر، یەک ستون: ناونیشان + دەق + تراکینگ + دووگمەکان) → بەشێکی کورت (وەک «٣ خزمەتگوزاری سەرەکی» یان «پەیوەندیمان پێوە بکە») → **(ئەگەر چالاک بکرێت)** بەشی بلۆگ (نوێترین بابەتەکان) و بەشی ستاف/تیم (تیمی ئێمە) → Footer کورت.
- **ڕیزبەندی:** کەمتر بەرز، scroll کەمتر؛ هەستێکی «مینیماڵ» و ڕوون.
- **تراکینگ:** لە ناوەڕۆکی Hero؛ دووگمەکانی پۆرتاڵ و staff لە Hero و ئەگەر دەتەوێت لە Header.
- **نەبوونی:** Stats بە شێوەی ئێستا، Services پڕ (٦ کارت)، Features پڕ (٦ ئایتم)، Contact پڕ (٤ ستون) — دەتوانرێت لە پەرەی minimal نەبن یان بە شێوەیەکی زۆر کورت و یەک بەش پیشان بدرێن.

ئەم جیاوازیە وادەکات **دوو پەرە تەواو جیاواز** بن لە دەستەواژەی «دوو پەرە»دا.

---

## ٥. تەکنیکی جێبەجێکردن (Technical Implementation)

### ٥.١ Backend
- **کلیلی سیتینگ:** `landingPageVariant` (یان `landingLayout`) — value: `classic` | `minimal`.
- **API ی public:** زیادکردنی `getLandingPageVariant` (وەک `getLandingTheme`) بۆ خوێندنەوەی `landingPageVariant`؛ default: `classic`.
- **نووسین:** لە سیتینگدا بە `trpc.settings.set` کلیلی `landingPageVariant` و value ی `classic` یان `minimal` دەنووسرێت.

### ٥.٢ Frontend — پەرەکە
- **Route:** هەر وەک ئێستا پەرەی سەرەکی `/` یەک route دەبێت؛ بەڵام ناوەڕۆکی ئەو route دەگۆڕێت بەپێی `landingPageVariant`.
- **شێوازی پێشنیارکراو:**
  - **`Home.tsx`:** وەک «router» ی پەرەی سەرەکی — خوێندنەوەی `landingPageVariant` (لە Context یان API)، و:
    - ئەگەر `classic` → رێندرکردنی **کۆمپۆنێنتی پەرەی کلاسیک** (ئەوەی ئێستا هەیە؛ دەتوانرێت بە شێوەی `HomeClassic.tsx` یان هەمان ناوەڕۆکی ئێستای `Home.tsx` بێت).
    - ئەگەر `minimal` → رێندرکردنی **کۆمپۆنێنتی پەرەی مینیماڵ** (`HomeMinimal.tsx` یان `LandingMinimal.tsx`).
  - **فایلەکان:**
    - `Home.tsx` — تەنها خوێندنەوەی variant و رێندرکردنی `HomeClassic` یان `HomeMinimal`.
    - `HomeClassic.tsx` (یان هەمان ناوەڕۆکی ئێستای Home) — هەموو سەکشنەکانی ئێستا (Header, Hero, Stats, Services, Features, CTA, Contact, Footer) و پشتگیری `landingTheme` (تاریک/ڕووناک/ئۆشن).
    - `HomeMinimal.tsx` — پەرەی نوێی مینیماڵ بە سەکشن و دیزاینی جیاواز؛ دەتوانێت پشتگیری `landingTheme` یان ڕووکاری تایبەتی خۆی داشته‌بێت.

### ٥.٣ Context یان API
- **Context ی نوێ (ئەگەر پێویست):** `LandingPageVariantContext` — وەک `LandingThemeContext`، بە `getLandingPageVariant` و state ی `variant`؛ Provider لە App.
- **جێگرەوە:** لە `Home.tsx` دا ڕاستەوخۆ `trpc.public.getLandingPageVariant.useQuery()` بەکارهێنرێت؛ سادەترە ئەگەر تەنها لە Home بەکار دەهێنرێت.

### ٥.٤ سیتینگ (UI)
- **شوێن:** لە پەڕەی **Settings**، لە تابی «ڕووکاری پەرەی یەکەم» یان تابی جیای **«جۆری پەرەی سەرەکی»** — هەڵبژاردنی **پەرەی پڕ (کلاسیک)** یان **پەرەی مینیماڵ**.
- **کۆمپۆنێنت:** کارت یان radio بۆ هەر جۆرێک (ناونیشان، وەسف، preview ی بچووک)، کلیک بۆ هەڵبژاردن، `settings.set({ key: 'landingPageVariant', value })`؛ دوای سەرکەوتوویی toast و reload یان invalidate.
- **پەیوەندی لەگەڵ ڕووکار:** ڕووکاری لاندینگ (تاریک/ڕووناک/ئۆشن) دەتوانێت لە هەردوو پەرەدا کار بکات؛ یان تەنها لە Classic، و لە Minimal ڕووکارێکی سادە (وەک تەنها تاریک/ڕووناک) بەردەست بێت.

### ٥.٥ لۆگۆ، ناونیشان، ژمارە مۆبایل و هەموو تایبەتمەندییەکان لە ڕێکخستنەکانی سیستەم (Single Source of Truth)

**بنەما:** هەموو ئەو داتایانەی لە پەرەی لاندینگ (کلاسیک و مینیماڵ) پیشان دەدرێن و پەیوەندیان بە کۆمپانیا و پەیوەندییەوە هەیە **دەبێت لە ڕێکخستنەکانی سیستەم وەربگیرێن** — ئەوەی کە لە **سیتینگ (ڕێکخستنەکان)** دامان ناوە. هیچ هاردکۆدکردن و هیچ ڕێکخستنێکی دووبارە بۆ پەرەی لاندینگ نەبێت.

- **لۆگۆ:** لە `company_info.logoUrl` (سیتینگی زانیاری کۆمپانیا) — هەمان لۆگۆی کە لە پسووڵە و داشبۆرد بەکاردێت.
- **ناونیشان / ناوی کۆمپانیا:** لە `company_info.name` (و بەپێی زمان `nameKu`، `nameAr` ئەگەر پێویست بێت) — هەمان ناو لە هەموو شوێنێکی سیستەم.
- **ژمارە مۆبایل / تەلەفۆن:** لە `company_info.phone` و `company_info.phone2` — بەکارهێنان لە بەشی پەیوەندی و Footer و هەر شوێنێکی تر لە پەرەی لاندینگ.
- **ئیمەیڵ:** لە `company_info.email`.
- **ناونیشان:** لە `company_info.address` (و `addressKu`، `addressAr` ئەگەر پێویست).
- **ماڵپەڕ:** لە `company_info.website` ئەگەر لە پەرەی لاندینگ لینک بەکاربهێنرێت.

**جێبەجێکردن:** هەردوو پەرە (HomeClassic و HomeMinimal) دەبێت **هەمان API/هۆک** بەکاربهێنن بۆ خوێندنەوەی زانیاری کۆمپانیا — وەک `useCompanyInfo()` یان public API ی `getCompanyInfo` / سیتینگی `company_info` — و هیچ نرخێکی نووسراو (hardcoded) بۆ لۆگۆ، ناو، ژمارە، ئیمەیڵ، ناونیشان لە پەرەکەدا نەبن. ئەمە وادەکات **یەک سەرچاوەی ڕاست** بێت: گۆڕانکاری لە سیتینگ خۆکارانە لە پەرەی ویبسایت دەردەکەوێت.

## ٦. پلانی وردتری پەرەی مینیماڵ (Minimal Page Design)

- **Header:** لۆگۆ + ناو (+ ئەگەر دەتەوێت دووگمەکانی پۆرتاڵ و staff)؛ سادە و کەم.
- **Hero:**
  - ناونیشانی سەرەکی (هەر یەک ڕیز).
  - دەقی کورت.
  - خانەی تراکینگ (هەمان فەنکشنی Quick Track).
  - دووگمەکانی «پۆرتاڵی کڕیار» و «چوونەژوورەوەی ستاف».
- **بەشی ناوەڕۆک (یەک):** وەک «٣ خزمەتگوزاری» یان «پەیوەندیمان پێوە بکە» — یەک ڕیز کارت یان لیستێکی کورت؛ بێ ئامار و بێ بەشی Features پڕ.
- **Footer:** لۆگۆ + مۆڵەت + لینکی پەیوەندی یان تەنها دەقێکی کورت.

ئەم پلانە وادەکات **پەرەی دووەم تەواو جیاواز** بێت لە پەرەی یەکەم، نەک تەنها گۆڕینی رەنگ.

---

## ٦.١ تایبەتمەندی یەک: بەشی بلۆگ لە پەرەی ویبسایت (Blog Section on Landing)

**ئامانج:** لۆژیکی بلۆگی سیستەم (بلۆگی ئێستا لە سیستەمەکە) لە **پەرەی ویبسایت** نیشان بدرێت — ئەیە واتا لە پەرەی سەرەکی (لاندینگ) بتوانین بابەتەکانی بلۆگ پیشان بدەین.

- **چی نیشان دەدرێت:** لیستی (یان کارتی) بابەتەکانی بلۆگی سیستەم — وەک «٣ یان ٦ نوێترین بابەت»؛ ناونیشان، کورتە، لینک بۆ پەرەی وردی بلۆگ، و ئەگەر هەبێت وێنە.
- **شوێن:** دەتوانرێت لە **هەردوو پەرە**دا بەردەست بێت:
  - لە **پەرەی کلاسیک:** بەشێکی نوێ «بلۆگ / نوێترین بابەتەکان» (ئەگەر چالاک بکرێت لە سیتینگ).
  - لە **پەرەی مینیماڵ:** بەشێکی «نوێترین بابەتەکان» لە دوای Hero یان بەشی خزمەتگوزاری.
- **داتا:** خوێندنەوە لە API ی بلۆگی ئێستا (public list ی بابەتەکان)؛ سنووری ژمارە (limit) بۆ لاندینگ؛ فلتەری published / visible.
- **سیتینگ (ئەگەر پێویست):** کلیلی وەک `landingShowBlog` (true/false) یان `landingBlogLimit` (٣، ٦، …) بۆ چالاک/ناچالاککردن و ژمارەی بابەت لە پەرەی سەرەکی.

ئەمە وادەکات **بلۆگی سیستەم لە پەرەی ویبسایت (لاندینگ) نیشان بدرێت** بە لۆژیکی یەکگرتوو.

---

## ٦.٢ تایبەتمەندی دوو: بەشی ستاف/تیم — بەڕێوەبردن لە سیستەم و نیشاندان لە پەرەی یەکەم (Staff/Team Section — Managed in Admin, Shown on Landing)

**ئامانج:** بەشێک لە **پەرەی یەکەم (لاندینگ)** هەبێت کە **ستاف/تیمی کۆمپانیا** پیشان بدات؛ **دیسکڕیپشنی ستاف** لە **فرۆنتیندی سیستەم (ئەدمین)** دەنووسرێت و دەستکاری دەکرێت، و ئەنجام لە پەرەی سەرەکی نیشان دەدرێت.

- **لە پەرەی لاندینگ (فرۆنتی):** بەشێک وەک «تیمی ئێمە» یان «ستافی ئێمە» — کارت یان ڕیزی کەسەکان بە ناو، ڕۆڵ/ناونیشان، وەسف (دیسکڕیپشن)، و ئەگەر هەبێت وێنە. هەموو ئەم داتایە لە سیستەمەوە دێت.
- **لە سیستەم (ئەدمین):** بەشی **بەڕێوەبردنی ستافی پەرەی سەرەکی** (وەک لە ڕێکخستنەکان یان مێنیوی جیای «ستاف / تیم بۆ پەرەی سەرەکی»):
  - زیادکردن / سڕینەوە / دەستکاریکردنی ئایتمی ستاف: **ناو**، **ناونیشان/ڕۆڵ** (وەک «بەڕێوەبەری گشتی»)، **دیسکڕیپشن** (دەقی کورت)، **وێنە** (ئەگەر هەبێت)، **ترتیب** (order).
  - داتاکە لە DB یان settings دەپاشەکەوتێن (وەک خشتەی `landing_team` یان JSON لە سیتینگ `landingTeamMembers`).
- **API:**
  - **Public:** `getLandingTeam` — گەڕاندنەوەی لیستی ستاف/تیم بۆ نیشاندان لە پەرەی لاندینگ (بێ چوونەژوورەوە).
  - **Admin:** زیادکردن/نوێکردنەوە/سڕینەوەی ئایتمی ستاف؛ پاشەکەوتکردن لە DB یان settings.
- **شوێنی نیشاندان:** بەشی «تیمی ئێمە» دەتوانرێت لە **هەردوو پەرە** (کلاسیک و مینیماڵ) یان تەنها لە یەکێکیان بەردەست بێت؛ پێشنیار: لە هەردوو پەرەدا بەردەست بێت، بەڵام لە مینیماڵدا بە شێوەیەکی کورتتر (وەک ٣–٤ کەس).

ئەمە وادەکات **خۆمان لە فرۆنتیندی سیستەم (ئەدمین) دیسکڕیپشنی ستاف بنووسین و لە پەرەی یەکەمی ویبسایت نیشان بدرێت**.

| **٢** | جیاکردنەوەی ناوەڕۆکی ئێستا: دروستکردنی `HomeClassic.tsx` (یان مۆڤێکردنی ناوەڕۆکی ئێستای Home بۆیە)؛ `Home.tsx` دەبێت تەنها variant بخوێنێت و `HomeClassic` یان `HomeMinimal` رێندر بکات | ٠.٥–١ ڕۆژ |
| **٣** | دروستکردنی `HomeMinimal.tsx` — Header، Hero، بەشی کورت، Footer؛ هەمان فەنکشنە سەرەکیەکان (تراکینگ، لینکەکان) | ١–١.٥ ڕۆژ |

## ٨. کورتە (Summary)

- **ئێستا:** یەک پەرەی لاندینگ هەیە؛ تەنها ڕووکار (تاریک/ڕووناک/ئۆشن) لە سیتینگ دەگۆڕێت.
- **دوای جێبەجێکردن:** دوو **جۆری پەرە** — **کلاسیک (پڕ)** و **مینیماڵ**؛ لە سیتینگ هەڵبژاردنی «کام پەرە وەک سەرەکی پیشان بدرێت»؛ پەرەکان تەواو لە یەکتر جیاوازن لە ڕیزبەندی و سەکشن و شێوازدا.
- **تایبەتمەندی زیادکراو:**
  1. **بلۆگ:** لۆژیکی بلۆگی سیستەم لە پەرەی ویبسایت (لاندینگ) نیشان دەدرێت — بەشی «نوێترین بابەتەکان» لە کلاسیک و/یان مینیماڵ؛ داتا لە API ی بلۆگ؛ ئەگەر پێویست چالاک/ناچالاک و limit لە سیتینگ.
  2. **ستاف/تیم:** بەشێکی «تیمی ئێمە» لە پەرەی یەکەم؛ دیسکڕیپشنی ستاف لە **فرۆنتیندی سیستەم (ئەدمین)** دەنووسرێت و بەڕێوە دەبرێت؛ داتاکە لە DB یان settings؛ public API `getLandingTeam` بۆ نیشاندان لە لاندینگ.
- **تەکنیک:** `landingPageVariant` لە settings؛ `getLandingPageVariant` public API؛ لە `Home.tsx` رێندرکردنی `HomeClassic` یان `HomeMinimal` بەپێی variant؛ سیتینگ بۆ هەڵبژاردنی جۆری پەرە؛ بلۆگ و ستاف وەک بەشەکانی زیادکراو لە هەردوو پەرەدا (یان بەپێی سیتینگ).
- **لۆگۆ و ناو و ژمارە و هتد:** هەموو ئەم تایبەتمەندیانە لە **ڕێکخستنەکانی سیستەم** (زانیاری کۆمپانیا / company_info) وەردەگیرن؛ هیچ دووبارەکردنەوە و هیچ هاردکۆد لە پەرەکەدا نەبێت.

ئەگەر پێت باشە، دەتوانین یەکەم قۆناغ (Backend + جیاکردنەوەی Home/HomeClassic) دەستپێبکەین و دواتر HomeMinimal، بلۆگ، ستاف/تیم، Settings و i18n تەواو بکەین.
