# پلانی: یەک ئۆردەر نەمبەر → چەند تراکینگ نەمبەر (کارتۆنە جیاکان)

## ئامانج
ئەوەی سیستەم بتوانێت **یەک ئۆردەر** بە **چەند تراکینگ نەمبەر** بەسترێت (وەک کاتێک ئۆردەرەکە بە چەند کارتۆن دەگات، هەر کارتۆنێک تراکی جیای هەبێت).

## بارەی ئێستا
- **fullPackageOrders** یەک خانەی `trackingNumber` هەیە (یەک بە یەک، unique).
- ئاگادارکردنەوەی تراکینگ: ئۆردەرەکان بێ تراکینگ نیشان دەدات (`trackingNumber` بەتاڵ).
- پاکەت کە دەگات بە تراکینگەوە دەگەڕێنرێتەوە بۆ ئۆردەر (`getFullPackageOrderByTrackingNumber`).

## پلانی تەکنیکی

### ١. تابلۆی نوێ: `fullPackageOrderTrackings`
| خانە | جۆر | وەسف |
|------|-----|------|
| id | int, PK | |
| fullPackageOrderId | int, FK → fullPackageOrders | ئۆردەرەکە |
| trackingNumber | varchar(100), UNIQUE | ژمارەی تراک (هەر تراک جیاواز) |
| cartonIndex | int, optional | ژمارەی کارتۆن (١، ٢، ٣...) بۆ ڕیزبەندی |
| createdAt | timestamp | |

- **پەیوەندی:** یەک ئۆردەر → چەند ڕیز لەم تابلۆە (چەند تراکینگ).
- `fullPackageOrders.trackingNumber` دەمێنێتەوە بۆ **کۆمپات** (یەکەم تراک یان null). ئەگەر هەر تراکێک لە تابلۆی نوێ بێت، ئۆردەر «تراکی هەیە» دادەنرێت.

### ٢. وەرگرتنی ئۆردەر بە تراکینگ
- **ئێستا:** `getFullPackageOrderByTrackingNumber(tracking)` تەنها لە `fullPackageOrders.trackingNumber` دەگەڕێت.
- **دوای گۆڕان:** یەکەم لە `fullPackageOrderTrackings` بگەڕێن بە `trackingNumber`؛ ئەگەر نەدۆزرایەوە، لە `fullPackageOrders.trackingNumber` بگەڕێن (کۆمپات).

### ٣. ئاگادارکردنەوەی تراکینگ
- **ئۆردەر «بێ تراکینگ»:**  
  هیچ ڕیزێک لە `fullPackageOrderTrackings` بۆ ئەو ئۆردەرە نییە **و** `fullPackageOrders.trackingNumber` بەتاڵ بێت.
- **ئۆردەر «تراکی هەیە»:**  
  لانیکەم یەک ڕیز لە `fullPackageOrderTrackings` یان `fullPackageOrders.trackingNumber` پڕ بێت.
- ژمارەدان و ئاستی ئاگاداری (warning/urgent/critical) وەک ئێستا دەمێنێت، بەڵام لەسەر «هەبوونی هیچ تراکێک» نەک تەنها یەک خانە.

### ٤. UI – پەڕەی ئاگادارکردنەوەی تراکینگ
- **دیالۆگی «زیادکردنی تراکینگ»:**  
  - ئێستا: یەک فیلدی تراکینگ و «پاشەکەوت».  
  - نوێ: **لیستەی تراکینگەکان** — دەتوانیت «تراک زیاد بکە» بکەیت و چەند تراکینگ داخڵ بکەیت (وەک کارتۆن ١، ٢، ٣). پاشەکەوت هەموویان لە `fullPackageOrderTrackings` تۆمار دەکات.
- لە لیستی ئۆردەرەکاندا: ئەگەر ئۆردەرێک چەند تراکی هەبێت، نیشان بدە (وەک «٣ تراک») یان کلیک کرد ئەوانە بڵاو بکەرێتەوە.

### ٥. پاکەت و لینککردن
- کە پاکەتێک بە تراکینگێک دەگات، لینککردن وەک ئێستا دەبێت: گەڕان بە `getFullPackageOrderByTrackingNumber(tracking)` — کە ئێستا لە تابلۆی نوێ + خانەی کۆن دەگەڕێت.
- **packages:** هەر پاکەتێک هەر یەک `trackingNumber` و یەک `fullPackageOrderId` هەیە؛ ئەگەر چەند پاکەت بە هەمان ئۆردەر بەسترابن (چەند کارتۆن)، هەموویان هەمان `fullPackageOrderId` دەبن بەڵام `trackingNumber` جیاواز.

### ٦. Migration و کۆمپات
- **Migration:** دروستکردنی تابلۆی `fullPackageOrderTrackings`.  
- **داتای کۆن:** ئۆردەرەکانی ئێستا کە `trackingNumber` پڕن؛ دەتوانین (ئارەزوومەندانە) یەک ڕیز بۆ هەر یەک لە `fullPackageOrderTrackings` زیاد بکەین بۆ یەکسانکردن، یان بە جێهێشتنی خانەی کۆن تەنها لە تابلۆی نوێ بگەڕێن و کۆن بەکار بهێنین بۆ «یەکەم تراک» تەنها لە شوێنەکانی کۆن.

## ڕیزبەندی جێبەجێکردن
1. **DB:** زیادکردنی تابلۆی `fullPackageOrderTrackings` و migration.
2. **Backend:**  
   - CRUD بۆ تراکینگەکانی ئۆردەر (list, add, delete).  
   - گۆڕینی `getFullPackageOrderByTrackingNumber` بۆ گەڕان لە تابلۆی نوێ + کۆن.  
   - گۆڕینی `getOrdersPendingTracking` و ئاماری ئاگاداری بۆ «هەبوونی هیچ تراکێک» (لە نوێ + کۆن).  
   - update fullPackage: مۆڕەتی «زیادکردنی تراک» بۆ نوێکردنەوەی تابلۆی نوێ (و ئەگەر پێویست بوو یەکەم تراک لە fullPackageOrders همیشە بکەین).
3. **Frontend:**  
   - لە پەڕەی ئاگادارکردنەوەی تراکینگ: دیالۆگی زیادکردنی **چەند تراکینگ** (لیست + زیادکردن/سڕینەوە).  
   - نیشاندانی ژمارەی تراکەکان لەسەر ئۆردەر (وەک «٣ تراک») لە خولێکدا.

## کورتە
- **یەک ئۆردەر → چەند تراکینگ** بە تابلۆی `fullPackageOrderTrackings` جێبەجێ دەکەین.
- ئاگادارکردنەوە و لینکی پاکەت وەک ئێستا کار دەکەن، بەڵام لەسەر «هەبوونی هیچ تراکێک» و «گەڕان بە هەر تراکێک».
- UI: لە ئاگادارکردنەوەی تراکینگ دەتوانیت جارێک چەند تراکینگ زیاد بکەیت بۆ هەر ئۆردەرێک.
