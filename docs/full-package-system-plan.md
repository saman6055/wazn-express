# پلانی سیستەمی فول پاکیج - Wazn Express

## پوختە

ئەم بەڵگەنامەیە پلانێکی تەواو و پڕۆفیشناڵ پێشکەش دەکات بۆ نوێکردنەوەی سیستەمی فول پاکیج لە Wazn Express. سیستەمی نوێ دوو جۆری سەرەکی کڕین پشتگیری دەکات:

1. **کڕینی فول پاکیج (Full Package Purchase)**: کۆمپانیا کاڵا دەکڕێت و بە نرخی بەرزتر دەیفرۆشێتەوە بە کڕیار
2. **کڕین بە عمولە (Commission Purchase)**: کۆمپانیا بۆ کڕیار کاڵا دەکڕێت و تەنها عمولەی خزمەتگوزاری وەردەگرێت

---

## بەشی یەکەم: کڕینی فول پاکیج (Full Package Purchase)

### ڕوونکردنەوەی پرۆسە

| قۆناغ | باس | نمونە |
|-------|------|-------|
| **1. داواکاری** | کڕیار داوای کڕینی کاڵا دەکات | کڕیار دەیەوێت مۆبایلێک بکڕێت |
| **2. کڕین** | کۆمپانیا کاڵاکە دەکڕێت بە نرخی کڕین | نرخی کڕین: $10 |
| **3. نرخدانان** | کۆمپانیا نرخی فرۆشتن دیاری دەکات | نرخی فرۆشتن: $25 |
| **4. گەیاندن** | کاڵا لە باچێکدا دەنێردرێت | باچی ئاسمانی یان دەریایی |
| **5. گەیشتن** | کاڵا دەگات و نرخی گواستنەوە حیساب دەکرێت | نرخی گواستنەوە: $5 |
| **6. حیساب** | پارە لەسەر حسابی کڕیار دەچێت | کۆی گشتی: $25 |
| **7. قازانج** | قازانج = نرخی فرۆشتن - نرخی کڕین - نرخی گواستنەوە | قازانج: $25 - $10 - $5 = $10 |

### فۆرمولای حیسابکردن

```
قازانج = نرخی_فرۆشتن - نرخی_کڕین - نرخی_گواستنەوە

نمونە:
- نرخی کڕین (purchasePriceUsd): $10
- نرخی فرۆشتن (sellingPriceUsd): $25
- نرخی گواستنەوە (shippingCostUsd): $5 (لە باچەکە حیساب دەکرێت)
- قازانج (profitUsd): $25 - $10 - $5 = $10
```

### گۆڕانکارییەکانی داتابەیس بۆ فول پاکیج

| فیڵد | جۆر | باس |
|------|-----|------|
| `orderType` | enum | `"full_package"` - جۆری سفارش |
| `purchasePriceUsd` | decimal | نرخی کڕین (تێچووی کۆمپانیا) |
| `purchasePriceCny` | decimal | نرخی کڕین بە یوان چینی |
| `sellingPriceUsd` | decimal | نرخی فرۆشتن بە کڕیار |
| `shippingCostUsd` | decimal | نرخی گواستنەوە (لە باچ حیساب دەکرێت) |
| `profitUsd` | decimal | قازانجی کۆمپانیا |
| `batchId` | int | باچی گواستنەوە |
| `packageId` | int | پاکەتی پەیوەست |
| `isChargedToCustomer` | boolean | ئایا پارە لەسەر حسابی کڕیار چووە |
| `chargedAt` | timestamp | کاتی چوونی پارە |

## بەشی دووەم: کڕین بە عمولە (Commission Purchase)

### ڕوونکردنەوەی پرۆسە

| قۆناغ | باس | نمونە |
|-------|------|-------|
| **1. داواکاری** | کڕیار داوای کڕینی کاڵا دەکات | کڕیار لینکی کاڵا دەنێرێت |
| **2. نرخدانان** | کۆمپانیا نرخی کاڵا + عمولە دیاری دەکات | نرخی کاڵا: $10، عمولە: $3 |
| **3. پارەدان** | کڕیار پارەی کاڵا + عمولە دەدات | کۆی گشتی: $13 |
| **4. کڕین** | کۆمپانیا کاڵاکە دەکڕێت | کاڵا دەکڕدرێت بە $10 |
| **5. گەیاندن** | کاڵا لە باچێکدا دەنێردرێت | باچی ئاسمانی یان دەریایی |
| **6. گەیشتن** | کاڵا دەگات و نرخی گواستنەوە حیساب دەکرێت | نرخی گواستنەوە: $5 |
| **7. حیساب** | نرخی گواستنەوە لەسەر حسابی کڕیار دەچێت | نرخی گواستنەوە: $5 |
| **8. قازانج** | قازانجی کۆمپانیا = عمولە + قازانجی گواستنەوە | عمولە: $3 |

### فۆرمولای حیسابکردن

```
قازانجی_کۆمپانیا = عمولەی_کڕین + قازانجی_گواستنەوە

نمونە:
- نرخی کاڵا (itemPriceUsd): $10
- عمولەی کڕین (commissionFeeUsd): $3
- کۆی پارەدانی کڕیار پێش گواستنەوە: $13
- نرخی گواستنەوە (لە باچ): $5 (جیاوازە لە قازانجی عمولە)
- قازانجی کۆمپانیا لە عمولە: $3
- قازانجی گواستنەوە: جیاکراوە لە باچ
```

### گۆڕانکارییەکانی داتابەیس بۆ کڕین بە عمولە

| فیڵد | جۆر | باس |
|------|-----|------|
| `orderType` | enum | `"commission"` - جۆری سفارش |
| `itemPriceUsd` | decimal | نرخی کاڵا (ڕاستەقینە) |
| `itemPriceCny` | decimal | نرخی کاڵا بە یوان چینی |
| `commissionFeeUsd` | decimal | عمولەی کڕین |
| `commissionRate` | decimal | ڕێژەی عمولە (ئەگەر بەپێی ڕێژە بێت) |
| `totalPaidByCustomer` | decimal | کۆی پارەدانی کڕیار (کاڵا + عمولە) |
| `shippingCostUsd` | decimal | نرخی گواستنەوە (لە باچ) |
| `isPrepaid` | boolean | ئایا پارەی کاڵا و عمولە دراوە |
| `prepaidAt` | timestamp | کاتی پارەدانی پێشوەخت |

### خشتەی fullPackageOrders (نوێکراوە)

```sql
-- گۆڕینی orderType بۆ سێ جۆر
orderType ENUM('full_package', 'commission', 'resale') NOT NULL DEFAULT 'full_package'

-- فیڵدەکانی نوێ
itemPriceUsd DECIMAL(10,2)           -- نرخی ڕاستەقینەی کاڵا
itemPriceCny DECIMAL(10,2)           -- نرخی کاڵا بە یوان
commissionFeeUsd DECIMAL(10,2)       -- عمولەی کڕین
totalPaidByCustomer DECIMAL(10,2)    -- کۆی پارەدانی کڕیار
isPrepaid BOOLEAN DEFAULT FALSE      -- ئایا پارەی پێشوەخت دراوە

isChargedToCustomer BOOLEAN DEFAULT FALSE  -- ئایا نرخی گواستنەوە چووە
chargedAt TIMESTAMP                  -- کاتی چوونی پارە
estimatedArrivalDate DATE            -- ڕێکەوتی چاوەڕوانکراوی گەیشتن
```

### خشتەی نوێ: fullPackagePayments

```sql
CREATE TABLE fullPackagePayments (
  id INT AUTO_INCREMENT PRIMARY KEY,

  customerId INT NOT NULL,

  ledgerTransactionId INT,  -- پەیوەندی بە تۆماری حساب
```

## پرسیارەکان بۆ دڵنیابوون

پێش دەستپێکردنی جێبەجێکردن، پێویستە ئەم پرسیارانە وەڵام بدرێنەوە:

1. **عمولەی کڕین**: ئایا عمولە بڕێکی جێگیرە (بۆ نمونە $3) یان ڕێژەیەکە (بۆ نمونە 10%)؟

2. **پارەدانی پێشوەخت**: ئایا کڕیار پێویستە پارەی کاڵا + عمولە پێشوەخت بدات پێش کڕین؟

3. **نرخی گواستنەوە**: ئایا نرخی گواستنەوە جیاکراوە لە نرخی فرۆشتن یان تێکەڵە؟

4. **پیشاندانی قازانج**: ئایا قازانج لە ڕاپۆرتی باچ پیشان بدرێت یان ڕاپۆرتی جیاوازی هەبێت؟

5. **ڕێکەوتی گەیشتن**: چۆن ڕێکەوتی چاوەڕوانکراو دیاری دەکرێت؟
