# بەشی یەکەم: سیستەمەکانی ئێستا

## 1. سیستەمی باچ (Batch System)

### 1.1 مەبەست
باچ کۆمەڵەیەکە لە پاکەتەکان کە پێکەوە لە چین دێن بە یەک شیپمێنت.

### 1.2 وۆرکفلۆ

```
┌─────────────────────────────────────────────────────────────────┐
│                    ژیانی باچێک (Batch Lifecycle)                │
└─────────────────────────────────────────────────────────────────┘

1️⃣ دروستکردن (Creating)
   ↓
   • ئەدمین باچێکی نوێ دروست دەکات
   • زانیاری: کۆدی باچ، شوێنی هاتن، جۆری شیپمێنت، بەرواری چاوەڕوان
   • بارودۆخ: "Preparing"
   
2️⃣ لە ڕێگادا (In Transit)
   ↓
   • باچ لە چین بەرەو عێراق
   • تراکینگ نەمبەری شیپمێنت زیاد دەکرێت
   • بارودۆخ: "In Transit"
   
3️⃣ لە گومرک (At Customs)
   ↓
   • باچ دەگاتە گومرکی عێراق
   • دۆکیومێنتەکان پرۆسێس دەکرێن
   • بارودۆخ: "At Customs"
   
4️⃣ گەیشتووە (Delivered)
   ↓
   • باچ دەگاتە کۆگای Wazn Express
   • تێچووی ڕاستەقینەی شیپمێنت (Calculated Cost) تۆمار دەکرێت
   • بارودۆخ: "Delivered"
   • ئاگادارکردنەوە دەنێردرێت بۆ هەموو خاوەنەکانی پاکەتەکان
   
5️⃣ داخراو (Closed)
   ↓
   • هەموو پاکەتەکانی باچ پرۆسێس کراون
   • حیساباتەکان تەواو بووە
   • بارودۆخ: "Closed"
```

### 1.3 زانیاریەکانی باچ

```javascript
{
  batchCode: "BATCH-2026-001",
  origin: "Guangzhou, China",
  shippingMethod: "Air Regular", // Air Regular, Air Irregular, Sea
  totalWeight: 45.5, // KG
  totalVolume: 2.3, // CBM
  packageCount: 32,
  estimatedCost: 822.00, // USD - پێشبینی
  calculatedCost: 844.00, // USD - ڕاستەقینە دوای گەیشتن
  status: "delivered",
  departureDate: "2026-01-10",
  arrivalDate: "2026-01-13",
  createdBy: "Admin User"
}
```

### 1.4 حیسابات

**تێچووی شیپمێنت:**
- تێچووی باچ لەسەر هەموو پاکەتەکانی ناوی دابەش دەکرێت
- فۆرمیولا: `شیپمێنت بۆ هەر پاکەت = (کێشی پاکەت ÷ کۆی کێش) × کۆی تێچووی باچ`

**نموونە:**
```
کۆی تێچووی باچ: $844
کۆی کێش: 45.5 KG

پاکەتی A (2 KG): (2 ÷ 45.5) × 844 = $37.10
پاکەتی B (3.5 KG): (3.5 ÷ 45.5) × 844 = $64.93
```

## 2. سیستەمی پاکەتی ئاسایی (Regular Package System)

### 2.1 مەبەست
پاکەتە ساکارەکان کە کڕیارەکان خۆیان لە چین دەنێرن بۆ ئادرێسی Wazn Express.

### 2.2 وۆرکفلۆ

```
┌─────────────────────────────────────────────────────────────────┐
│              ژیانی پاکەتی ئاسایی (Regular Package Lifecycle)    │
└─────────────────────────────────────────────────────────────────┘

1️⃣ تۆمارکردن (Registration)
   ↓
   • کڕیار زانیاری پاکەتەکەی دەنێرێت (تراکینگ، ناو، کێش)
   • ئەدمین پاکەت تۆمار دەکات لە سیستەم
   • بارودۆخ: "Pending"
   
2️⃣ خستنە ناو باچ (Batch Assignment)
   ↓
   • پاکەت دەخرێتە ناو باچێک
   • بارودۆخی پاکەت = بارودۆخی باچ
   
3️⃣ گەیشتن بە کۆگا (Warehouse Arrival)
   ↓
   • باچ دەگات، پاکەتەکە لەگەڵیدایە
   • تێچووی شیپمێنت حیساب دەکرێت
   • بارودۆخ: "In Warehouse"
   • ئاگادارکردنەوە بۆ کڕیار
   
4️⃣ ئامادەکردن بۆ گەیاندن (Delivery Preparation)
   ↓
   • کڕیار پارەی شیپمێنت دەدات
   • پاکەت ئامادە دەکرێت بۆ گەیاندن
   • بارودۆخ: "Ready for Delivery"
   
5️⃣ گەیاندن (Delivered)
   ↓
   • پاکەت دەگاتە دەستی کڕیار
   • بارودۆخ: "Delivered"
```

### 2.3 حیسابات

**تێچووەکان:**
```
تێچووی شیپمێنت = (کێشی پاکەت ÷ کۆی کێشی باچ) × تێچووی باچ
خزمەتگوزاری ناوخۆیی = $2 - $5 (بەپێی قەبارە)
کۆی تێچوو = شیپمێنت + خزمەتگوزاری
```

**نموونە:**
```
کێشی پاکەت: 2.5 KG
تێچووی شیپمێنت: $46.40
خزمەتگوزاری: $3.00
───────────────────────
کۆ: $49.40
```

## 3. سیستەمی فول پاکێج (Full Package System)

### 3.1 مەبەست
Wazn Express کاڵا لە چین دەکڕێت و بە نرخێکی زیادتر دەیفرۆشێتەوە بە کڕیار.

### 3.2 وۆرکفلۆ

```
┌─────────────────────────────────────────────────────────────────┐
│                ژیانی فول پاکێج (Full Package Lifecycle)         │
└─────────────────────────────────────────────────────────────────┘

1️⃣ داواکردن (Order Placement)
   ↓
   • کڕیار داوای کاڵایەک دەکات
   • ئەدمین نرخی کڕین و فرۆشتن دیاری دەکات
   • بارودۆخ: "Pending"
   
2️⃣ پەسەندکردن (Approval)
   ↓
   • کڕیار نرخەکە پەسەند دەکات
   • بارودۆخ: "Approved"
   
3️⃣ کڕین (Purchasing)
   ↓
   • Wazn Express کاڵا لە فرۆشیار دەکڕێت
   • نرخی کڕین تۆمار دەکرێت
   • بارودۆخ: "Purchased"
   
4️⃣ تراکینگ (Tracking Added)
   ↓
   • فرۆشیار کاڵا دەنێرێت
   • تراکینگ نەمبەر زیاد دەکرێت
   • بارودۆخ: "Tracking Added"
   
5️⃣ لە کۆگای چین (In China Warehouse)
   ↓
   • کاڵا دەگاتە کۆگای چین
   • وێنە دەگیرێت و دەنێردرێت بۆ کڕیار
   • بارودۆخ: "In China Warehouse"
   
6️⃣ خستنە ناو باچ (Batch Assignment)
   ↓
   • کاڵا دەخرێتە ناو باچێک
   • بارودۆخ: "In Batch"
   
7️⃣ لە ڕێگادا (In Transit)
   ↓
   • باچ بەرەو عێراق
   • بارودۆخ: "In Transit"
   
8️⃣ گەیشتووە (Arrived)
   ↓
   • باچ دەگاتە کۆگای عێراق
   • تێچووی شیپمێنت حیساب دەکرێت
   • قازانج حیساب دەکرێتەوە
   • بارودۆخ: "Arrived"
   • ئاگادارکردنەوە بۆ کڕیار
   
9️⃣ گەیەندرا (Delivered)
   ↓
   • کاڵا دەگاتە دەستی کڕیار
   • کڕیار پارە دەدات
   • بارودۆخ: "Delivered"
```

### 3.3 حیسابات

**فۆرمیولاکان:**
```javascript
// 1. تێچووی شیپمێنت
shippingCost = (packageWeight ÷ batchTotalWeight) × batchTotalCost

// 2. قازانج
profit = ((sellingPrice - purchasePrice) × quantity) - shippingCost

// 3. کۆی وەرگیراو لە کڕیار
totalReceived = sellingPrice × quantity

// 4. کۆی تێچوو
totalCost = (purchasePrice × quantity) + shippingCost
```

**نموونەی ڕاستەقینە:**
```
نرخی کڕین: $22.00
نرخی فرۆشتن: $36.00
بڕ: 1
کێش: 2 KG
تێچووی شیپمێنت: $44.00

حیساب:
─────────────────────────
نرخی فرۆشتن:           $36.00
- نرخی کڕین:           $22.00
- تێچووی شیپمێنت:      $44.00
═════════════════════════
قازانج:                -$30.00 (زەرەر!)
```

**تێبینی گرنگ:** لە نموونەکەی سەرەوە، ئەم فرۆشتنە زەرەرە چونکە تێچووی شیپمێنت زۆر بەرزە. بۆیە پێویستە نرخی فرۆشتن بەرزتر بکرێتەوە.

## 4. سیستەمی داواکاری کڕین (Purchase Request System)

### 4.1 مەبەست
کڕیار لینکی کاڵایەک دەنێرێت، Wazn Express دەیکڕێت و بە کۆمیشنێک دەیفرۆشێتەوە.

### 4.2 جیاوازی لەگەڵ فول پاکێج

| خاڵ | فول پاکێج | داواکاری کڕین |
|-----|-----------|---------------|
| **نرخی کاڵا** | Wazn دیاری دەکات | کڕیار دەیزانێت (لە لینک) |
| **قازانج** | (فرۆشتن - کڕین) | (فرۆشتن - نرخی کاڵا) |
| **ڕیسک** | لەسەر Wazn | لەسەر کڕیار |
| **پەسەندکردن** | نرخی فرۆشتن | نرخی کۆتایی |

### 4.3 وۆرکفلۆ

```
┌─────────────────────────────────────────────────────────────────┐
│           ژیانی داواکاری کڕین (Purchase Request Lifecycle)      │
└─────────────────────────────────────────────────────────────────┘

1️⃣ داواکردن (Request Submission)
   ↓
   • کڕیار لینکی کاڵا دەنێرێت
   • نرخی کاڵا: $50 (لە لینک)
   • بارودۆخ: "Pending"
   
2️⃣ نرخدان (Quotation)
   ↓
   • Wazn کۆمیشن زیاد دەکات: $50 + $15 = $65
   • نرخی فرۆشتن: $65
   • بارودۆخ: "Quoted"
   
3️⃣ پەسەندکردن (Approval)
   ↓
   • کڕیار نرخەکە پەسەند دەکات
   • بارودۆخ: "Approved"
   
4️⃣ کڕین (Purchasing)
   ↓
   • Wazn کاڵا دەکڕێت بە $50
   • بارودۆخ: "Purchased"
   
5️⃣ ... (هەمان وەک فول پاکێج)
```

### 4.4 حیسابات

**فۆرمیولاکان:**
```javascript
// 1. نرخی فرۆشتن
sellingPrice = itemPrice + commission

// 2. قازانج
profit = ((sellingPrice - itemPrice) × quantity) - shippingCost

// 3. کۆی وەرگیراو
totalReceived = sellingPrice × quantity

// 4. کۆی تێچوو
totalCost = (itemPrice × quantity) + shippingCost
```

**نموونە:**
```
نرخی کاڵا: $50.00
کۆمیشن: $15.00
نرخی فرۆشتن: $65.00
بڕ: 2
تێچووی شیپمێنت: $25.00

حیساب:
─────────────────────────
وەرگیراو لە کڕیار:      $130.00 (65 × 2)
- نرخی کاڵا:            $100.00 (50 × 2)
- تێچووی شیپمێنت:       $25.00
═════════════════════════
قازانج:                 $5.00
```

## 5. سیستەمی کڕین بە عمولە (Commission System)

### 5.1 مەبەست
کڕیار خۆی کاڵا دەکڕێت، Wazn تەنها شیپمێنت دەکات و کۆمیشنێک وەردەگرێت.

### 5.2 وۆرکفلۆ

```
┌─────────────────────────────────────────────────────────────────┐
│            ژیانی کڕین بە عمولە (Commission Lifecycle)           │
└─────────────────────────────────────────────────────────────────┘

1️⃣ تۆمارکردن (Registration)
   ↓
   • کڕیار خۆی کاڵای کڕیوە
   • تراکینگ نەمبەر دەنێرێت
   • کۆمیشن دیاری دەکرێت (مەسەلەن $10)
   • بارودۆخ: "Pending"
   
2️⃣ گەیشتن بە کۆگای چین (China Warehouse)
   ↓
   • کاڵا دەگاتە کۆگای چین
   • وێنە دەگیرێت
   • بارودۆخ: "In China Warehouse"
   
3️⃣ خستنە ناو باچ (Batch Assignment)
   ↓
   • کاڵا دەخرێتە ناو باچێک
   • بارودۆخ: "In Batch"
   
4️⃣ گەیشتن (Arrival)
   ↓
   • باچ دەگات
   • تێچووی شیپمێنت حیساب دەکرێت
   • قازانج = کۆمیشن - شیپمێنت
   • بارودۆخ: "Arrived"
   
5️⃣ گەیەندرا (Delivered)
   ↓
   • کاڵا دەگاتە کڕیار
   • کڕیار کۆمیشن + شیپمێنت دەدات
   • بارودۆخ: "Delivered"
```

### 5.3 حیسابات

**فۆرمیولاکان:**
```javascript
// 1. قازانج
profit = commissionFee - shippingCost

// 2. کۆی وەرگیراو لە کڕیار
totalReceived = commissionFee + shippingCost

// 3. کۆی تێچوو
totalCost = shippingCost
```

**نموونە:**
```
کۆمیشن: $10.00
تێچووی شیپمێنت: $8.00

حیساب:
─────────────────────────
کۆمیشن:                 $10.00
- تێچووی شیپمێنت:       $8.00
═════════════════════════
قازانج:                 $2.00

وەرگیراو لە کڕیار:      $18.00 (10 + 8)
```

# بەشی دووەم: سیستەمی حیسابات و دارایی

## 1. جۆرەکانی داهات (Revenue Types)

### 1.1 داهاتی فول پاکێج
```javascript
{
  revenueType: "full_package_sale",
  amount: sellingPrice × quantity,
  cost: (purchasePrice × quantity) + shippingCost,
  profit: amount - cost,
  date: deliveryDate
}
```

### 1.2 داهاتی داواکاری کڕین
```javascript
{
  revenueType: "purchase_request_sale",
  amount: sellingPrice × quantity,
  cost: (itemPrice × quantity) + shippingCost,
  profit: amount - cost,
  date: deliveryDate
}
```

### 1.3 داهاتی کۆمیشن
```javascript
{
  revenueType: "commission_service",
  amount: commissionFee,
  cost: shippingCost,
  profit: amount - cost,
  date: deliveryDate
}
```

### 1.4 داهاتی شیپمێنتی پاکەتی ئاسایی
```javascript
{
  revenueType: "shipping_service",
  amount: shippingCost + serviceFee,
  cost: shippingCost,
  profit: serviceFee,
  date: deliveryDate
}
```

## 2. خشتەی داهات (Revenue Table)

```sql
CREATE TABLE revenues (
  id INT PRIMARY KEY AUTO_INCREMENT,
  recordDate DATE NOT NULL,
  revenueType ENUM(
    'full_package_sale',
    'purchase_request_sale', 
    'commission_service',
    'shipping_service'
  ),
  referenceType ENUM('fullPackageOrder', 'regularPackage', 'batch'),
  referenceId INT,
  customerId INT,
  amountUsd DECIMAL(10,2), -- داهات
  costUsd DECIMAL(10,2), -- تێچوو
  profitUsd DECIMAL(10,2), -- قازانج
  description TEXT,
  createdById INT,
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 3. پوختەی دارایی ڕۆژانە (Daily Financial Summary)

```sql
CREATE TABLE dailyFinancialSummaries (
  id INT PRIMARY KEY AUTO_INCREMENT,
  summaryDate DATE UNIQUE NOT NULL,
  
  -- داهات بەپێی جۆر
  fullPackageRevenue DECIMAL(10,2) DEFAULT 0,
  purchaseRequestRevenue DECIMAL(10,2) DEFAULT 0,
  commissionRevenue DECIMAL(10,2) DEFAULT 0,
  shippingRevenue DECIMAL(10,2) DEFAULT 0,
  
  -- کۆی داهات
  totalRevenue DECIMAL(10,2) DEFAULT 0,
  
  -- تێچوو
  totalCost DECIMAL(10,2) DEFAULT 0,
  
  -- قازانج
  totalProfit DECIMAL(10,2) DEFAULT 0,
  
  -- ئاماری فرۆشتن
  fullPackagesSold INT DEFAULT 0,
  purchaseRequestsSold INT DEFAULT 0,
  commissionsProcessed INT DEFAULT 0,
  regularPackagesShipped INT DEFAULT 0,
  
  updatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 4. ڕاپۆرتی قازانج (Profit Reports)

### 4.1 قازانج بەپێی جۆری پەت

```sql
SELECT 
  orderType,
  COUNT(*) as totalOrders,
  SUM(sellingPriceUsd * quantity) as totalRevenue,
  SUM((purchasePriceUsd * quantity) + shippingCostUsd) as totalCost,
  SUM(profitUsd) as totalProfit,
  AVG(profitUsd) as avgProfit
FROM fullPackageOrders
WHERE status = 'delivered'
  AND deliveredAt BETWEEN '2026-01-01' AND '2026-01-31'
GROUP BY orderType;
```

**ئەنجام:**
```
┌──────────────────┬────────┬──────────┬──────────┬─────────┬──────────┐
│ جۆری پەت         │ ژمارە  │ داهات    │ تێچوو    │ قازانج  │ ناوەند   │
├──────────────────┼────────┼──────────┼──────────┼─────────┼──────────┤
│ full_package     │ 45     │ $4,500   │ $3,200   │ $1,300  │ $28.89   │
│ purchase_request │ 28     │ $2,800   │ $2,100   │ $700    │ $25.00   │
│ commission       │ 15     │ $450     │ $300     │ $150    │ $10.00   │
└──────────────────┴────────┴──────────┴──────────┴─────────┴──────────┘
```

### 4.2 قازانج بەپێی بەروار

```sql
SELECT 
  DATE(deliveredAt) as date,
  COUNT(*) as orders,
  SUM(profitUsd) as dailyProfit
FROM fullPackageOrders
WHERE status = 'delivered'
  AND deliveredAt >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY DATE(deliveredAt)
ORDER BY date DESC;
```

# بەشی سێیەم: یەکخستنی سکان

## 1. سکان + باچ

### 1.1 وەرگرتنی باچ لە کۆگا

```
┌─────────────────────────────────────────────────────────────────┐
│                    Scan: Batch Receiving                        │
└─────────────────────────────────────────────────────────────────┘

کارمەند:
1. QR کۆدی باچ سکان دەکات
2. سیستەم زانیاری باچ پیشان دەدات:
   • کۆدی باچ: BATCH-2026-001
   • ژمارەی پاکەتەکان: 32
   • کێش: 45.5 KG
   • تێچووی چاوەڕوان: $822

3. کارمەند تێچووی ڕاستەقینە دەنووسێت: $844
4. دووگمەی "وەرگیرا" دەداتە

سیستەم:
✅ بارودۆخی باچ → "Delivered"
✅ تێچووی ڕاستەقینە تۆمار دەکات
```
