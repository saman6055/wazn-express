# پلانی تابێکی نوێ: کۆی قازانج + دیاریکردنی مەسروفاتی کۆمپانیا
## Plan: Aggregated Profit & Company Expense Summary Tab

ئەم پلانە بۆ **زیادکردنی تابێکی نوێ** لە ڕاپۆرتی قازانج (`/reports/profit`) نووسراوە: کۆکردنەوەی قازانج لە هەموو سەرچاوەکان و **دیاریکردنی سیستەمی مەسروفات** بۆ کۆمپانیا.

---

## ١. ئامانج

| ئامانج | وەسف |
|--------|------|
| **کۆی گشتی قازانج** | قازانجی پاکەتی ئاسایی + قازانجی فول پاکیج + عمولەی کرین بە ئۆردەر (کۆمیشن) + قازانجی خزمەتگوزاری — هەموویان کۆ بکرێتەوە. |
| **مەسروفاتی کۆمپانیا** | لەسەر بنەمای ئەو کۆی قازانجە، سیستەم **مەسروفاتی گونجاو** پێشنیار بکات (پلەبەندی، سنوور، بەراورد لەگەڵ مەسروفاتی ڕاستەقینە). |
| **بینراو پرۆفیشناڵ** | تابێکی سەربەخۆ بە کارت و خشتە و گرافیک، وەک باقی تابەکانی ڕاپۆرت. |

---

## ٢. سەرچاوەکانی داتا (لە کۆدەوە)

| سەرچاوە | تابل/داتا | ژمارە |
|---------|-----------|--------|
| **قازانجی فول پاکیج** | `fullPackageOrders`، `orderType = 'full_package'` | `SUM(profitUsd)` |
| **قازانجی کۆمیشن** | `fullPackageOrders`، `orderType = 'commission'` | `SUM(profitUsd)` |
| **پاکەتی ئاسایی** | `packages` (isCharged=true) | ئێستا تەنها `SUM(calculatedCostUsd)` = **داهات**؛ تابلەکە **قازانج** (cost vs revenue) ناگرێتەوە. دەتوانین بۆ ئەم تابە **داهاتی پاکەت** بە «بەشداریی داهات» بناسێنین، یان دواتر **قازانجی پاکەت** زیاد بکرێت ئەگەر تێچوو (cost) تۆمار بکرێت. |
| **قازانجی خزمەتگوزاری** | `extraServices` | `SUM(profitAmount)` — خانەی `profitAmount` هەیە. |

**کورتە:**  
- **کۆی قازانج (بە مانای تەنگ)** = فول پاکیج + کۆمیشن + قازانجی خزمەتگوزاری.  
- **داهاتی پاکەت** = `SUM(calculatedCostUsd)` لە پاکەتە گەیەندراوە تە Charged ەکان؛ دەتوانین وەک **کۆی گشتی داهات/قازانج** لەم تابەدا نیشان بدەین و لە خشتەدا جیابکەینەوە (داهات vs قازانج).

**مەسروفات:**  
- تابلە **`expenses`** (مەسروفاتی ڕاستەقینە) و **`expenseCategories`** (پۆلەکان) هەن.  
- بۆ ماوەی هەمان بەروار (ساڵ/مانگ)، `SUM(expenses.amountUsd)` = **کۆی مەسروفاتی کۆمپانیا**.

---

## ٣. لۆژیکی «دیاریکردنی مەسروفات» بە شێوەی سیستەمی

مەسروفات **دیاری نەکرێت** بە ئۆتۆماتیک؛ سیستەم دەتوانێت **پێشنیار و سنوور** بدات:

1. **نیشاندانی ڕاستەقینە:**  
   کۆی مەسروفات لە ماوەی هەمان ساڵ/مانگ (لە `expenses`)، و **سەرماوە** = کۆی قازانج − کۆی مەسروفات.

2. **پێشنیاری سنووری مەسروفات (Optional):**  
   - وەک «مەسروفاتی ئۆپراسیۆنی پێشنیارکراو»: بەڵگەنامە نەخشەکە **ڕێژەیەک** لە کۆی قازانج بدات (مثلاً ٢٠٪–٣٠٪) و بڵێت: «پێشنیار: مەسروفات لە X% قازانج زیاتر نەبێت».  
   - یان سنووری **بەپێی پۆل** (لە `expenseCategories`): بۆ هەر پۆلێک ڕێژەیەکی پێناسەکراو (ئەگەر دواتر لە settings زیاد بکرێت).

3. **بەراورد:**  
   مەسروفاتی ڕاستەقینە vs پێشنیار؛ ئەگەر مەسروفات > پێشنیار، ئاگاداری (رەنگی سوور/هۆڤەر) پیشان بدرێت.

4. **هەڵسەنگاندنی تەندروستی دارایی:**  
   - **سەرماوە = قازانج − مەسروفات.**  
   - ئەگەر سەرماوە نێگەتیڤ بێت، نیشان بدەین کە لە ماوەکەدا خەرجی زیاتر لە داهاتە.

## ۴. پلانی UI/UX بۆ تابێکی نوێ

### ۴.١ ناو و جێگە

- **ناوی تاب:** «کۆی گشتی و مەسروفات» / «Total & Expenses» (وەک کلیلی i18n: `profitReport.summaryExpenseTab`).
- **جێگە:** وەک **چوارەم تاب** لە ڕاپۆرتی قازانج (دوای: مانگانە | بەپێی جۆر | وردەکاری).

### ۴.٢ بەشی یەک: کۆی قازانج / داهات

- **فیلتەری بەروار:** هەمان ساڵ (و ئەگەر بیەوێت مانگ) وەک تابەکانی تر.
- **کارتە سەرەکیەکان (ئامار):**
  - قازانجی فول پاکیج
  - قازانجی کۆمیشن
  - داهاتی پاکەتی ئاسایی (یان قازانجی پاکەت ئەگەر دواتر ژماردراو بێت)
  - قازانجی خزمەتگوزاری
- **کۆی گشتی قازانج (یان داهات+قازانج):** کارتێکی گەورە یان ژمارەیەکی ڕوون.

### ۴.٣ بەشی دوو: مەسروفاتی کۆمپانیا

- **کۆی مەسروفات** لە هەمان ماوە (لە `expenses`).
- **خشتە یان لیست:** مەسروفات بەپێی **پۆل** (`expenseCategories`) — ناوەکانی پۆل و کۆی amountUsd بۆ هەر پۆلێک.
- **سەرماوە:** کۆی قازانج − کۆی مەسروفات، بە رەنگی سەوز/سوور بەپێی نێگەتیڤ یان نا.

### ۴.۴ بەشی سێ: پێشنیاری سیستەمی (دیاریکردنی مەسروفات)

- **پێشنیاری سنوور:**  
  «مەسروفاتی پێشنیارکراو (ئۆپراسیۆن): لە X% قازانج زیاتر نەبێت» — X لە settings یان نرخێکی default (مثلاً ٢٥٪).
- **بەراورد:**  
  مەسروفاتی ڕاستەقینە vs ئەم سنوورە؛ ئەگەر زیاتر بوو، نیشان بدەین «مەسروفات لە سنوورەکە تێپەڕیووە».
- **دەقێکی کورت:** وەک «بەپێی سیاستی دارایی، پێشنیار دەکرێت مەسروفات لە [X]% قازانج زیاتر نەبێت.»

### ۴.۵ گرافیک (ئەگەر گونجاو بێت)

- **Pie یان Bar:** بەشی قازانج (فول پاکیج، کۆمیشن، خزمەتگوزاری، پاکەت) و بەشی مەسروفات بەپێی پۆل.
- **Bar:** قازانج vs مەسروفات بە مانگ (ئەگەر فیلتەر بە ساڵ بێت).

## ۵. Backend (API / DB)

| کار | وەسف |
|-----|------|
| **فەنکشنی نوێ** | `getAggregatedProfitAndExpenses(year, month?)` — کۆی قازانج لە فول پاکیج، کۆمیشن، خزمەتگوزاری؛ داهات یان قازانجی پاکەت؛ کۆی مەسروفات؛ مەسروفات بەپێی پۆل. |
| **شوێن** | `server/db/reports.db.ts` (یان `finance.db.ts` بۆ بەشی مەسروفات). |
| **Router** | `fullPackage.getAggregatedProfitAndExpenses` یان `reports.getAggregatedProfitAndExpenses` — هەمان فیلتەری ساڵ/مانگ وەک ڕاپۆرتی قازانج. |
| **قازانجی خزمەتگوزاری** | `SELECT SUM(profitAmount) FROM extraServices WHERE createdAt BETWEEN ? AND ?` (و ئەگەر currency ی جیاواز هەبێت، وەرگێڕان بۆ USD). |
| **مەسروفات** | `SELECT categoryId, SUM(amountUsd) FROM expenses WHERE expenseDate BETWEEN ? AND ? GROUP BY categoryId`؛ join لەگەڵ `expenseCategories` بۆ ناوەکانی پۆل. |

---

## ۶. قەدەغە و تێبینیەکان

- **پاکەت:** ئێستا تەنها **داهات** (calculatedCostUsd) هەیە، **قازانج** لەسەر تابلەکە نییە؛ دەتوانین لەم تابەدا بە «داهاتی پاکەت» ناوی بێنین تا دواتر تێچوو (cost) زیاد بکرێت و قازانجی پاکەت ژماردرا.
- **پێشنیاری مەسروفات:** ڕێژەی X% دەتوانێت لە **Settings** ی سیستەم بێت (مثلاً «expenseRecommendationPercent: 25») بۆ گونجاوکردنی لەگەڵ سیاسەتی کۆمپانیا.
- **i18n:** هەموو دەقەکان بە `t("profitReport.xxx")` — کلیلە نوێکان: `summaryExpenseTab`, `aggregatedProfit`, `packageRevenue`, `serviceProfit`, `totalExpenses`, `expensesByCategory`, `netSurplus`, `recommendedExpenseLimit`, `expenseOverLimit`, `expenseRecommendationText`.

## ۷. ڕیزبەندی جێبەجێکردن

1. **Backend:** زیادکردنی `getAggregatedProfitAndExpenses` و endpoint ی tRPC.  
2. **i18n:** زیادکردنی کلیلەکانی `profitReport` بۆ ئەم تابە (کوردی، ئینگلیزی، عەرەبی، چینی).  
3. **کلاینت:** زیادکردنی تابە نوێکە و بەکارهێنانی داتای API؛ کارتە ئاماریەکان؛ خشتەی مەسروفات بەپێی پۆل؛ سەرماوە؛ پێشنیاری سنوور و بەراورد.  
4. **Settings (ئەگەر پێویست بێت):** خانەی «ڕێژەی پێشنیاری مەسروفات» (%).  
5. **Polish:** گرافیک، skeleton، empty state، RTL.

ئەگەر ئەم پلانە ڕازیت، دەتوانین لە قۆناغی ١ (Backend) دەست پێ بکەین.
