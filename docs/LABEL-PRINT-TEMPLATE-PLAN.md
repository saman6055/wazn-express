# پلان: بژاردەی پرینت و پرینتی لەیبڵ بە تێمپلەیتی سیتینگ

## ئامانج
- بژاردەی پرینت و پرینتی لەیبڵ **پرۆفیشنال** بن.
- لە **فەنکشنی دروستکردنی لەیبڵ** و **تیمپلەیتی سیتینگ** (داڕشتەی لەیبڵ) کار بکەن — یەک سەرچاوە بۆ هەردوو لاپەڕەی «پرینتی لەیبڵ» و «ئەنەلایزی باچ».

---

## ١. فەنکشنی هاوبەش (دروستکردنی لەیبڵ)

- **فایل:** `client/src/lib/labelPrintUtils.ts`
- **کار:** یەک فەنکشنی هاوبەش کە HTML ی لەیبڵەکان دروست بکات بەپێی:
  - **تێمپلەیت** (لە داتابەیس/سیتینگ): قەبارە (widthMm, heightMm)، شوێنی QR، نیشاندانی لۆگۆ، نیشاندانی تراکینگ، ناو، کۆد، مۆبایل، شار، کێش، جۆری گواستنەوە، کۆدی باچ، بەروار، نرخ، رەنگ، فۆنت، …
  - **پاکەتەکان:** لیستی پاکەت (تراکینگ، کێش، …)
  - **کڕیار:** ناو، کۆد، مۆبایل، شار (بۆ هەموو لەیبڵەکان یەک کڕیار)
  - **باچ:** کۆدی باچ، جۆری گواستنەوە
  - **کۆمپانیا:** ناوی کۆمپانیا
  - **QR codes:** ماپی تراکینگ → data URL (لە دەرەوە دروست دەکرێت و دەدرێتە ناو)
- **دەرچوو:** نووسینی HTML ی تەواوی پەڕە بۆ کردنەوەی پرینت (وەک ئەوەی لە لاپەڕەی «پرینتی لەیبڵ» هەیە).

---

## ٢. پەیوەندیکردنی لەگەڵ تێمپلەیتی سیتینگ

- **لیستی تێمپلەیتەکان:** `trpc.labelTemplates.list`
- **تێمپلەیتی بنەڕەتی:** `trpc.labelTemplates.getDefault` یان هەڵبژاردنی تێمپلەیتی default لە list.
- لە **هەردوو** شوێندا (پرینتی لەیبڵ + مۆدالی ئەنەلایزی باچ):
  - هەڵبژاردنی تێمپلەیت (dropdown) بە ناوی تێمپلەیتەکان.
  - لینک یان دوگمە بۆ «داڕشتەی تێمپلەیتەکان» (`/settings/label-templates`) بۆ گۆڕینی تێمپلەیت و رێکخستنەکان.

---

## ٣. لاپەڕەی ئەنەلایزی باچ (BatchFinancialReport)

- **داتا:** لیستی تێمپلەیتەکان + تێمپلەیتی هەڵبژێردراو (بنەڕەت: default).
- **مۆدالی وردەکاری کڕیار:**
  - بەشی **پرینتی لەیبڵ**:
    - هەڵبژاردنی تێمپلەیت (Select) + لینکی «داڕشتەی لەیبڵ» بۆ سیتینگ.
    - دوو بژاردە: فول پاکیج / ئاسایی + عمولە.
  - کاتێک کلیک دەکرێت بۆ پرینتی لەیبڵ:
    1. وەرگرتنی تێمپلەیتی هەڵبژێردراو (یان default).
    2. دروستکردنی QR بۆ هەر پاکەتێک.
    3. وەرگرتنی زانیاری کڕیار (ناو، کۆد، مۆبایل، شار) لە لیستی کڕیارەکان.
    4. بانگهێشتکردنی فەنکشنی هاوبەش `generateLabelsHtml(...)`.
    5. کردنەوەی پەڕەی پرینت.
- **ڕاپۆرتی پرینت (تیمپلەیت):** ئەگەر پێویست بێت دەتوانرێت دواتر تیمپلەیتی ڕاپۆرتی پرینت لە سیتینگ زیاد بکرێت؛ بۆ ئێستا ڕاپۆرتی پرینت وەک ئێستا دەمێنێتەوە (HTML ی تایبەتی خۆی).

---

## ٤. لاپەڕەی پرینتی لەیبڵ (LabelPrinting)

- **Refactor:** بەکارهێنانی هەمان فەنکشنی هاوبەش `generateLabelsHtml` لە `labelPrintUtils.ts` بۆ دروستکردنی HTML.
- هەڵبژاردنی تێمپلەیت و دروستکردنی QR و بانگهێشتکردنی فەنکشن — کۆد دووبارە نەبێتەوە، تەنها یەک سەرچاوە.

---

## ٥. پرۆفیشنالکردنی UI

- **ئەنەلایزی باچ (مۆدال):**
  - کارتی «تێمپلەیتی لەیبڵ»: Select + لینک بۆ سیتینگ.
  - دوو کارتی پرینتی لەیبڵ (فول پاکیج / ئاسایی+عمولە) وەک ئێستا، بەڵام پرینت بە تێمپلەیتی هەڵبژێردراو.
- **پرینتی لەیبڵ (لاپەڕە):**
  - هەمان تێمپلەیت و سیتینگ بە شێوەیەکی ڕوون و یەکگرتوو پیشان بدە.

---

## ترتیبەکانی جێبەجێکردن

| قۆناغ | کار |
|--------|-----|
| ١ | دروستکردنی `client/src/lib/labelPrintUtils.ts` (تایپەکان + `generateLabelsHtml`) |
| ٢ | لە BatchFinancialReport: fetch تێمپلەیتەکان، Select تێمپلەیت، لینک بۆ سیتینگ، پرینت بە فەنکشنی هاوبەش |
| ٣ | لە LabelPrinting: refactor بۆ بەکارهێنانی `generateLabelsHtml` لە util |

پاش ئەمە، بژاردەی پرینت و پرینتی لەیبڵ لە هەردوو شوێندا بە تێمپلەیتی سیتینگ و فەنکشنی یەکگرتووی دروستکردنی لەیبڵ کار دەکەن.
